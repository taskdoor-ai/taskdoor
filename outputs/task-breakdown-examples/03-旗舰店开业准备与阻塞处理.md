# 示例三：旗舰店开业准备与阻塞处理

> 人员与职责沿用测试平台预置资料；任务要求为测试示例设定。仅将「输入资料」发送给待测 AI，「参考验收」用于人工核对，不作为模型输入。本文件不是测试通过报告。

## 输入资料

### 团队组成与职责

| 成员 | 角色 | 责任范围 |
| --- | --- | --- |
| 许棠 | 区域项目经理 | 开业目标、跨岗位依赖、资源协调和升级决策 |
| 江岚 | 店长 | 门店人员、试营业演练和现场交接 |
| 黎川 | 工程经理 | 装修整改、设施移交、消防资料和承包商沟通 |
| 顾禾 | 商品计划 | 首批 SKU、补货节奏和陈列库存 |

| 宋沐 | 会员运营 | 活动权益、会员触达和核销流程 |
| 唐宁 | 食品质量 | 冷链记录、设备温度校准和食安验收 |
| 季文 | 人事培训 | 岗位排班、操作培训和应急演练 |

### 任务需求

旗舰店计划 9 月 26 日正式开业，请拆解剩余工作并推荐分工。说明哪些工作可以立即开始，哪些工作需要等待前置结果。

### 已知情况

- 首批商品共 380 个 SKU，其中常温 284 个、生鲜 96 个。
- 常温商品已到 268 个 SKU，剩余 16 个待补。
- 冷柜曾因空调启动而断电，只有 6 小时温度记录，最高达到 7.2℃。
- 冷柜验收要求为满载连续 24 小时保持 0—4℃，传感器完成校准。
- 工程仍有冷柜独立供电、后仓门封和应急照明标识三项未关闭。
- POS 的退款返券、跨日交班和断网重传尚未通过。
- 活动物料写明优惠不叠加，但当前 POS 配置允许叠加。
- 18 名员工中，14 人完成通识培训；收银实操 6/8，冷链实操 2/4。
- 当前只允许员工内测，未批准面向顾客试售生鲜。

### 整体完成标准

- 工程遗留问题全部关闭，设施移交资料完成签字。
- 冷柜供电整改后，满载连续 24 小时温度均为 0—4℃，校准记录齐全。
- 380 个 SKU 按确认的备货清单到齐，数量、效期和批次符合要求。
- 常温商品价签与 POS 售价一致，生鲜入库记录包含到货温度。
- 支付、退款返券、跨日交班和断网重传验收通过。
- 活动文案、权益规则与 POS 配置一致，优惠叠加测试符合确认规则。
- 18 人完成通识培训，收银实操 8/8、冷链实操 4/4 通过。
- 完成退款与停电演练，影响开业的遗留问题关闭并留档。
- 工程、食安、系统、库存和人员五项门禁均取得对应负责人确认，由许棠完成正式开业确认。

## 参考验收：任务拆解与分配

### 合理的责任分配

| 工作 | 建议负责人 | 关键协作或前置条件 |
| --- | --- | --- |
| 关闭工程遗留问题并移交 | 黎川 | 江岚参与现场交接 |
| 校准传感器并复验冷柜 | 唐宁 | 冷柜供电整改完成 |
| 补齐常温库存及预约生鲜 | 顾禾 | 生鲜入库等待冷柜验收通过 |
| 完成常温陈列与价签核对 | 江岚 | 顾禾提供商品资料，赵予协助价格核对 |
| 修复 POS 并完成联调 | 赵予 | 宋沐明确会员权益规则 |
| 核对活动权益与文案 | 宋沐 | 与 POS 配置保持一致 |
| 补齐培训和岗位实操 | 季文 | 江岚组织员工，专业人员提供指导 |
| 执行退款与停电演练 | 江岚 | 系统修复和供电整改完成 |
| 核对开业门禁 | 许棠 | 各专业负责人提交确认结果 |

### 测试通过条件

- [ ] 把供电整改分给黎川，把冷柜食安复验分给唐宁。
- [ ] 把会员权益规则分给宋沐，把系统配置和修复分给赵予。
- [ ] 生鲜入库依赖冷柜验收，常温补货、陈列和培训可以继续。
- [ ] 不因冷柜当前温度恢复正常，就认定连续 24 小时验证通过。
- [ ] 不把员工培训签到当成岗位实操通过。
- [ ] 不把员工内测许可扩大为面向顾客营业许可。
- [ ] 不把全部验收工作笼统分配给项目经理。
- [ ] 拆解结果覆盖五项开业门禁，每项均有产物和可核查的完成标准。
