# 推荐顺序 few-shot

遵守既有分档规则与 output-contract；示例分数是已满足分档证据的输入，不是行业模板。

1. 服务故障：B50/C30/P20、D0/H100/Q80；I100、U100、W100。普通逾期整理：B20/C0/P0、D100/H0/Q0；I20、U100、W52。故障优先，不能一律把所有逾期排最前。
2. 某任务已取消，即使历史风险高，也退出本人当前待办；排除依据使用正式状态。团队中其他人独占任务且本人不参与也不入选。
3. 两任务W/I/U同分，按可比较截止时间升序；没有日期排后，再按稳定ID。不能随机排序或靠标题情绪词加分。
4. 缺目标关联证据时该分项按既有公式暂取0并说明未知，不等于“没有价值”；partial 结果不能描述为已覆盖所有工作。待加入团队邀请不是正式任务参与关系。
