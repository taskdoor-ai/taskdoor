# 责任分析 few-shot

完整输出遵循 output-contract.md；所有建议默认 suggested，writeReceipt=null。

1. 两项独立脚本交付可证明本人实际编写，当前责任仅“内容协作”。可以建议细化为脚本撰写，附两项贡献引用；不推断所有内容均由本人承担，不评价绩效。
2. 本人明确反馈“这次仅临时整理附件，不长期承担资料管理”。保留临时边界，feedbackRefs 使用实际反馈 ID；不能因参加三个讨论就建立持续职责。
3. 前轮建议基于责任v2，本轮正式责任v3已经修改。使用v3重新判断；旧建议不直接覆盖新文本。没有真实写入回执时不得输出 applied。
4. 只提供任务Owner字段，没有正文或贡献归属。不能将整项成果记为本人实际完成；有缺口返回partial，保留当前正式责任。
