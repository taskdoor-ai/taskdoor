# EWD few-shot：计算与未知

使用输出契约，例子只教计算，不提供当前任务事实。

1. 三项工作量 120、480、120 分钟，完成比例 100%、80%、40%。完成量=120+384+48=552，总量720，内部比例76.666…%，人天1.5，已完成1.15人天。状态变化不参与公式。
2. 同上但第三项进度未知。knownCompletedEwdMinutes=504，completedEwdMinutes 与 completionPercent=null，unconfirmedEwdMinutes=120；不把未知补成0，也不除以600宣称整体84%。
3. 父任务下两个中间层共享同一叶子引用。按有效叶子 ID 去重，只计一次；父级额外范围未覆盖时整体未知，不将叶子全完成作为父目标已达成。
4. 历史点由总量960完成240变成总量720完成240。范围减少240，新增完成量0；不能把比例上升解释为新产出。
5. 三点估算 O=60、M=120、P=240 分钟。expectedMinutes=(60+4*120+240)/6=130，planner ewdHours=130/60。无人值守等待48小时不计入人工投入。历史不可比时不用 history 基础。
