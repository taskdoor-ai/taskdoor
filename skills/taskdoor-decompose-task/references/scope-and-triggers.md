# 分析范围与触发事件

本文件说明调用方如何确定需要分析的任务，以及本 Skill 如何处理该次输入。Skill 只做只读分析，不订阅事件、不启动定时器、不监听 CLI／MCP，也不自行保存候选或创建任务。事件表是调用规则，不代表后台服务已经接通。

## 以当前任务为分析单位

固定 `currentTask.id` 为本次父任务，所有新增候选只属于它的下一层。树关系限定默认读取范围，变化还须与本次事项相关；不能因为根到叶路径有任意变化，就整条路径或整棵树重跑。

| 范围 | 读取内容与边界 |
| --- | --- |
| 当前任务 | 当前有效字段，相关讨论根及回复，相关文件有效正文、必要文件讨论与版本。用户只问某条讨论时先围绕该事项，不自动展开全部历史 |
| 直属子任务 | 先取得完整可见目录及范围、状态，核对已有承接；只有范围覆盖确需证明时才补读其讨论、文件或有关后代结果 |
| 父级与祖先 | 仅核对实际适用的目标、范围、硬期限、权限或层级约束；无需沿父链读取每个任务的全部讨论和文件 |
| 兄弟与其他分支 | 默认不展开。当前材料明确引用且对判断确有必要时，在权限内补读；引用不授权改父子归属或扩大本轮交付 |

正式父级约束、当前任务范围、子任务范围、讨论和文件正文分别保留真实来源与版本。覆盖说明只针对本次授权的相关范围，缺页、未知和失权不伪装成“无任务承接”。输入适配遵守[上下文读取](context-retrieval.md)。

## 谁在什么时候调用

| 变化或请求 | 需要处理的范围 |
| --- | --- |
| 用户主动要求拆解、整理跟进事项或重新分析 | 当前任务及该次要求的相关来源；主动重分析应实际调用，不能仅重读旧结果冒充 |
| 外部 Agent 读取任务、总结／回复讨论、处理文件时发现值得独立跟进的事项 | 先完成原请求，再按需调用；用户只授权读取或回复不等于授权创建。没有具体跟进价值时不机械调用 |
| 当前任务相关讨论／回复新增、编辑或删除 | 评估变化所在讨论及确实受其影响的事项。新增讨论即使不在旧候选引用中，也可能带来新事项；不能只监听旧引用而漏掉新增需求 |
| 另一条讨论变化 | 不自动作废无关候选。仅有明确事项关联、范围变更或冲突时才重新核对受影响部分 |
| 当前任务相关文件新增、有效正文更新、删除、替代或文件讨论变化 | 只处理确实影响本次事项、已有交付或来源有效性的材料。目录排序、纯移动等不改变依据的操作不要求模型重析 |
| 当前任务处理范围、已有目标或标准实质变化 | 当前任务的受影响事项；目标或标准为空是合法信息，不作为失败。仅标准重排不重析 |
| 子任务新增、删除、移动或范围／成果发生相关变化 | 核对当前任务是否已有承接、是否存在新缺口；无关子任务讨论或上传本身不触发父级重析 |
| 承接任务状态变化 | 已有精确来源关系时可直接更新显示并校验覆盖，不必为状态展示调用模型。完成或取消不自动恢复创建建议；确有新增范围时再分析 |
| 实际引用的父级约束变化 | 只重新核对引用了该约束、确实受影响的下级；不向所有后代广播。父级无关讨论不触发下级 |
| 推荐人员所依据的职责、成员有效性或权限变化 | 失权内容立即停用；必要时更新受影响的人员建议。人员、日期变化不自动扩展任务范围或触发全树分析 |
| 忽略建议 | 调用方保留该事项及依据的处理决定；没有实质新信息不再次推荐，不因刷新或仅改名复活旧事项 |

页面打开、切换 Tab、展开／收起、置顶、读取通知、AI 结果自身保存，都不制造新的分析事件。同一输入版本已有有效结果时复用；首次缺结果、结果已过期或用户主动重分析时才按需取得结果。仅连接 CLI／MCP 不会持续监听；外部 Agent 在下一次交互时核对，后台即时更新必须由应用另行调度。

## 调度、失效和创建前校验

1. 应用接收真实保存成功的变化，先按来源关系和实际范围筛选受影响任务。子任务变化只在影响覆盖或结果时向必要父级传播；相关性尚不明确时局部核对，不能盲目全树重算，也不能把未知当作无关。
2. 合并同一任务连续变化，取最新授权快照调用本 Skill。讨论跟进只分析新增或变化的相关事项，复用无关候选与用户编辑；需要完整拆解时才覆盖当前任务的完整未承接范围。
3. 依据失效的候选暂停直接创建，不能把旧结论继续当作当前建议。模型结果回来后，调用方再次核对来源版本与权限，迟到旧结果不覆盖较新结果或用户处理决定；失败如实标待更新，不能宣称刷新成功。
4. 用户确认创建前，再核对最新讨论、已有承接、权限、成员和父级。依据未变时不为点击创建再强制跑一轮模型；依据变化先重新核对或分析，再决定是否仍适用。写入只由本 Skill 之外的获授权执行流程完成。

当前输入／输出版本仍为 `taskdoor.subtask-suggestions.v1`，事件名称、队列、订阅及共享建议记录属于调用方，不让模型伪造事件或新增运行时协议字段。来源、范围和忽略事实未传入时，不能声称已完整核对或自动同步页面。
