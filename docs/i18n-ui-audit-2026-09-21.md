# 主应用多语言检查（2026-09-21）

检查范围：从 `src/App.tsx` 导入关系可达的 99 个组件。历史演示页、测试实验室和未挂载旧组件不计入主界面覆盖。

## 本次修复

- AI 工具下拉菜单、连接弹窗、当前任务上下文预览及复制／打开结果提示。
- 通知筛选、空态和三条内置通知；按记录 ID 与原文匹配，用户改写的内容保留。
- 标签管理、依赖选择、日期控件、子任务入口、创建历史与 AI 调整的静态文案、动态按钮和可访问名称。
- 文件浏览、上传、编辑、讨论、删除与版本记录的静态标签和主要提示。
- 系统文案集中在 `globalUiMessages.json`，以稳定词条 ID 保存中英文本。兼容调用通过原始系统文案查表，不扫描 DOM、不自动翻译用户内容。

## 验证与保护

`node scripts/check-ui-i18n.cjs` 检查主应用可达组件的 JSX 文本及直接字符串属性。允许语言名称“简体中文”。此检查不覆盖变量、所有模板字符串、服务端响应或文件内容，不能作为全产品完成率。

定向测试：`server/globalUiI18n.test.ts` 检查词条参数一致、中文保留、通知身份与修改保护、AI 启动结果真实性和上下文标准完整句翻译。既有 Mock、设置／活动及进度的定向测试继续验证原始值保护。

浏览器确认当前任务 AI 预览的标题、目标、完成标准、人员、日期和标签，以及通知列表和文件页面主要控件显示英文。未执行剪贴板导出、外部工具启动或对外发送。

## 仍需迁移，不能宣称完成

- 历史文件正文，包括部分内置 PDF 抽取文本。它们参与编辑版本、选区偏移和讨论引用，后续需要正文双语基线及引用坐标策略，不能直接替换文本而破坏原引用。
- 高级分析、模型生成结果和部分校验错误仍来自中文数据／协议，静态 JSX 检查无法证明这些分支已全部英文。
- AI 导出的原始上下文及真实服务端语言协议未改写；本次预览翻译不改变导出内容和工具启动权限。
- 日期业务时区、账户跨设备语言偏好仍保持现有边界。

用户自由填写的任务、评论、姓名和文件内容保留原文，不列作未翻译系统文案。

2026-09-21：统一 Acceptance criteria、Collaborators、Dependencies、No due date、Log in / Log out；区分 Pin 操作与 Pinned tasks 分组，设置岗位说明统一用“职责”。定义与依据见 docs/i18n-terminology.md，不改变角色和确认流程。

检查主应用可达组件中的中文字符串，区分存储枚举、翻译源文、用户内容和漏译。修复创建历史系统摘要、推荐等级与本地推荐说明、人员溢出名单及可访问姓名、英文人员搜索、文件弹窗标题／图标、保存与读取失败提示、AI 连接时间与示例命令载荷。人员推荐排序算法不变。

静态检查新增直接 ui() 调用的词条覆盖检查，避免包了函数仍无译文；当前可达组件数量为 100。类型检查及 28 项定向测试通过（术语、全局文案、设置、创建、登录及 mock），不是全量业务测试。浏览器确认英文概览字段、负责人可访问姓名、推荐等级及搜索 Mo Chen 返回对应成员；没有添加或移除成员、发布讨论或注册。

历史文件正文、部分真实服务端错误及 AI 输出协议仍按上方迁移边界处理，不能宣称全产品零中文。未挂载的实验／历史组件不作为主应用完成度。
