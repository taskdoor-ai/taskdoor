# 任务进度档位 Tooltip 设计

## 对象与目标

- **对象：** Task 详情、子任务等位置共用的四格进度摘要。
- **目标：** 用户悬浮任一格时，可以知道该格代表的进度名称；键盘和辅助技术获得同等信息。
- **边界：** Tooltip 只解释档位，不允许点击修改进度，也不改变 Task 状态、进度来源或燃起图数据。

## 档位语义

进度条使用 0–4 格五个状态：

| 已填充格数 | 名称 |
| --- | --- |
| 0 格 | 未形成结果 |
| 1 格 | 少量完成 |
| 2 格 | 部分完成 |
| 3 格 | 大部分完成 |
| 4 格 | 基本完成 |

- 0 格没有已点亮色块，由进度主标签直接显示“未形成结果”；四个未点亮格仍可悬浮查看各自档位名称。
- 用户明确确认 Task 完成后，主标签显示“已完成”；四格仍表示进度档位，第四格的说明保持“基本完成”，避免把 AI 推测与用户确认混为一谈。
- 未知或非法进度继续显示“暂无评估”，四格全部保持未点亮但仍可查看档位名称；它不显示来源，也不伪装成已有 0 格评估。

## 数值映射

沿用现有进度比例，补齐“少量完成”区间：

- `ratio === 0`：0 格；
- `0 < ratio < 0.25`：1 格；
- `0.25 <= ratio < 0.5`：2 格；
- `0.5 <= ratio < 0.9`：3 格；
- `0.9 <= ratio <= 1`：4 格。

## 交互与视觉

1. 四个格子无论是否点亮，都支持鼠标悬浮和键盘聚焦。
2. Tooltip 显示在当前格上方，文案依次为“少量完成”“部分完成”“大部分完成”“基本完成”，不暴露“几格”的内部表达。
3. 当前悬浮或聚焦的格子增加轻微高亮和清晰焦点环；不使用点击态，不出现可编辑暗示。
4. Tooltip 离开悬浮或失去焦点后关闭；同一时刻只展示一个。
5. 进度主标签和来源标签保持原有布局，不增加常驻说明文字。

## 无障碍

- 每格拥有独立的可访问名称，只使用对应完成度名称，不包含格数。
- 键盘可依次聚焦四格并打开同一 Tooltip。
- 外层摘要仍提供当前进度、来源或未知状态的完整说明，不用颜色作为唯一信息。

## 最小验证

- 渲染测试覆盖 0–4 格对应名称和填充数量。
- 测试四个格子均具有正确的 Tooltip 文案与可访问名称，包括未点亮格子。
- 覆盖“用户确认完成”和“暂无评估”两个边界，确保未知状态只有四个未点亮格且来源语义不变。
- 只运行与进度档位组件直接相关的测试和类型检查，不运行全量测试。
