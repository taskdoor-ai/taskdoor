# 统一任务创建入口设计

## 对象与目标

- 对象：任务工作区中的新建任务页，以及任务详情的子任务 Tab。
- 用户：需要新建独立任务或在现有任务下新增子任务的团队成员。
- 本次决策：去掉“当前方式 / 分步方式”的创建类型选择，所有创建都进入同一套对话创建页；从任务详情发起时固定创建为当前任务的子任务。
- 成功证据：用户不再需要选择创建类型；点击“新增子任务”后立即看到带父任务路径的创建对话；确认创建后任务归属不会偏离发起时的父任务。

## 方案选择

采用统一入口方案：保留 `TaskCreationPage` 作为唯一创建体验，移除创建方式切换及 `TaskCreationLinearPage` 的运行时入口。相比仅隐藏切换控件，这能同时删除不可达的双分支状态；相比另建子任务创建页，它能复用同一套需求描述、补问、方案确认和失败保留能力。

## 交互与信息架构

### 独立新建任务

- 侧栏或任务列表的“新建任务”继续进入统一对话创建页。
- 面包屑显示“任务 / 新建任务”。
- AI 可根据需求建议关联已有任务，沿用现有关系判断流程。

### 新建子任务

- 子任务 Tab 去掉“AI 调整子任务安排”。
- “新增子任务”不再展开内嵌表单，改为跳转统一对话创建页。
- 跳转时保存发起任务的 ID 和完整任务路径。
- 面包屑显示“任务 / 上级路径… / 当前父任务 / 新建任务”；路径中的已有任务可点击返回对应任务，末项为当前页。
- 父任务归属固定为发起任务。创建方案不再出现“独立创建”或改换父任务的关系决策。
- 确认创建时调用既有按父任务写入的创建能力；方案若包含拆分项，则它们成为新子任务的下级任务。
- 取消创建返回发起的父任务，而不是统一返回任务列表。

## 状态与边界

- 切换团队、完成创建或重新从独立入口发起时，清除父任务上下文，避免串用旧路径。
- 若父任务在创建期间被删除或不属于当前团队，保留输入并阻止确认，提示重新从有效任务发起。
- 加载、生成失败、保存失败与键盘焦点沿用统一创建页现有行为。
- 移动端面包屑允许横向滚动或按现有样式换行，不增加独立导航组件。

## 代码边界

- `App.tsx`：维护可选的创建父任务上下文，区分独立新建与子任务新建，负责返回与最终写入。
- `TaskCreationExperience.tsx`：收敛为唯一创建页挂载层，不再保存创建模式。
- `TaskCreationPage.tsx`：接收固定父任务与路径，渲染面包屑并在规划结果中保持固定归属。
- `TaskDetail.tsx`：子任务区仅保留跳转式“新增子任务”入口。
- 删除不再使用的内嵌子任务表单引用；旧数据结构和历史任务不迁移。

## 验收项

1. 页面上不存在“当前方式”“分步方式”和“AI 调整子任务安排”。
2. 独立新建显示“任务 / 新建任务”，仍能完成原有对话创建。
3. 任意层级任务点击“新增子任务”后，显示完整路径加“新建任务”。
4. 子任务创建过程中没有切换为独立任务的入口，确认后直接归属发起任务。
5. 取消子任务创建返回原父任务；独立创建取消返回任务列表。
6. 父任务失效时不写入任务，输入不丢失并给出错误提示。
