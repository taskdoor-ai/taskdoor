# 当前情况与下一步建议移除跳转入口设计

## 目标

任务详情中的“当前情况”和“下一步建议”只展示 Mock 投影生成的文字，不再展示“查看任务”“核对完成标准”“查看子任务”等跳转入口。

## 设计

- 展示层忽略 `TaskSituationItem.reference`，继续保留该字段及底层 Mock 数据，避免改变排序、摘要和其他数据消费者。
- 两个区块的标题、摘要、列表顺序、原因文字、更新时间以及完成状态／燃起图保持不变。
- `TaskCurrentSituation` 即使收到 `onOpenReference` 回调，也不渲染按钮或来源标签；其他页面中的任务名称、文件、讨论和燃起图入口不在本次范围。

## 验收

- 当前情况与下一步建议的文字仍可见。
- 两个区块内不出现 `task-situation-reference`、`task-situation-source-label` 或 reference 的可见标签。
- 定向渲染测试通过；按用户工作流，不运行全量测试或双重审查。
