# 任务连接本地 AI 设计

## 背景

用户需要从任务详情把当前任务交给本机 AI 工具继续处理。现有项目已经具备“连接 AI”页面、真实工具 Logo、Deep Link 启动方式及一个偏复杂的 `AiConnectionDialog`，但任务详情缺少一个清晰的整任务连接入口，原弹窗也展示了超出本次决策所需的上下文配置。

## 目标

- 在任务详情提供明确的“连接 AI”入口。
- 弹窗只要求用户选择本地工具并连接。
- 自动把当前任务在用户权限范围内可访问的上下文交给所选工具。
- 复用现有连接 AI 功能中的 ChatGPT、Claude Code、CodeBuddy、Cursor 名称、Logo 与启动方式。
- 让用户清楚知道上下文受当前账号权限约束。

## 非目标

- 不让用户逐项勾选任务字段、文件、活动或子任务。
- 不在弹窗中编辑 Prompt、工作目标、期望输出或本地路径。
- 不在本期实现本地成果自动回传。
- 不新增第五种工具，也不建立新的工具配置系统。

## 入口

任务详情头部的主要操作区增加“连接 AI”按钮。入口作用于整个当前任务，不与某条活动、某个文件或一段选中文本绑定。现有细粒度 AI 操作可继续保留，但整任务入口是本功能的主要路径。

点击后打开模态弹窗。按钮和弹窗标题都使用“连接 AI”，避免“个人 Agent”“客户端”等额外术语。

## 弹窗设计

弹窗采用单列阅读顺序：

1. 顶部标题与一句说明。
2. 横向工具选择区。
3. 当前任务信息。
4. 权限说明。
5. 取消与连接按钮。

### 工具选择

工具以等宽选项横向排列，使用项目已有真实 Logo：ChatGPT、Claude Code、CodeBuddy、Cursor。每项展示 Logo、名称和一句极短能力描述。默认选择 ChatGPT；选中态同时使用边框与对勾，不只依赖颜色。

窄屏时工具项改为单列，保证名称、Logo 和点击区域可读。

### 带入的信息

该区域只展示当前任务，不枚举上下文内部的字段类型。内容包括：

- 任务名称；
- 任务编号；
- 当前状态；
- 所属项目或任务路径。

补充一句说明：连接后，所选 AI 将获得该任务的相关上下文并自行选择工作所需信息。系统实际生成上下文包时可包含当前用户有权访问的任务详情、关系、文件、活动及人员信息，但弹窗不把这些实现细节展开为配置项。

### 权限说明

在任务信息下方使用独立、低干扰但清晰可见的安全提示：

> 仅带入你当前有权查看的信息，不会获得额外权限。

权限在服务端或上下文构建层执行，不能只依赖前端文案或隐藏字段。

### 连接动作

主按钮文案随选择变化，例如“连接 Claude Code”。点击后：

1. 基于当前用户身份和当前任务 ID 构建任务上下文包；
2. 复用已有 Deep Link 或剪贴板降级方式启动工具；
3. 启动期间按钮进入忙碌态，防止重复触发；
4. Deep Link 无法携带 Prompt 的工具先复制上下文，再打开客户端。

## 组件与数据流

- `TaskDetail` 负责提供当前任务入口，并构造整任务级连接请求。
- `AiConnectionDialog` 负责工具选择、任务摘要、权限提示和启动状态。
- `agentIcons` 继续作为工具 Logo 的唯一来源。
- 上下文序列化函数继续集中在连接组件或独立协议模块中，不在入口按钮内拼接 Prompt。
- 启动成功后关闭弹窗；失败或无法确认启动时保留可重试状态，并提示上下文是否已经复制。

## 验收标准

1. 任一任务详情均可通过明显的“连接 AI”入口打开弹窗。
2. 弹窗顶部横向展示四种工具及其真实 Logo。
3. 弹窗下方只展示当前任务摘要，不出现上下文勾选、工作说明或目录配置。
4. 切换工具会同步更新连接按钮文案。
5. 弹窗明确提示上下文基于当前用户权限。
6. 四种工具沿用现有启动策略，忙碌时不能重复提交。
7. 弹窗支持 Escape、遮罩关闭、键盘聚焦与窄屏布局。

## 测试策略

- 单元测试：整任务上下文包包含任务身份信息，空字段被安全忽略，权限声明固定存在。
- 组件测试：入口打开弹窗、四种工具 Logo、选择态、按钮文案、关闭行为和忙碌态。
- 启动策略测试：可携带 Prompt 的 Deep Link 与仅支持剪贴板的工具走正确分支。
- 回归测试：活动、文件或洞察上的既有细粒度 AI 入口不受影响。
- 手工检查：桌面与窄屏、浅色与深色主题、键盘操作以及真实 Logo 清晰度。
