# 任务范围快捷筛选设计

## 当前决定（2026-09-20）

任务范围移出搜索框，并入外部快捷筛选栏，与状态、排序并列。替代此前搜索框内嵌范围下拉或胶囊的布局，释放关键词输入空间。

完整定稿见 [任务列表 PRD v0.2](../../prd/modules/01-task-list.md)（PRD-0002）；后续搜索空态、清除入口、对齐和选中样式以该文为准。

## 布局与交互

- 第一行：关键词搜索框、清除搜索按钮、高级筛选入口。
- 第二行：左侧将任务范围与带状态／筛选图标的 `全部状态 ▾` 紧凑分组，右侧独立放置带上下箭头的 `最近更新 ▾`，不加分隔线。范围图标随选项变化：全部任务用列表、我负责的用单人、我参与的用多人。筛选生效时图标与文字同步高亮，排序保持中性色。
- 范围菜单包含“全部任务／我负责的／我参与的”，显示对应数量，采用单选语义；触发器显示当前范围。菜单文字为 13px，数量采用同字体的 12px 常规字重与辅助色，数字等宽右对齐。
- 复用现有 `TaskListFilters.scope`，切换只修改范围，保留关键词和其他条件。高级筛选不重复呈现或统计范围。
- 切换范围后选中结果集首条任务；结果为空时不保留筛选外详情。明确选择本人负责时省略重复负责人头像。
- 窄屏允许快捷栏换行并保持触控高度；复用菜单的键盘方向键、Enter、Escape 和焦点返回行为。
- 空、加载、失败、无权限和数据过期状态沿用工作区原有处理，本次不引入新数据源或状态。

## 验收

1. 搜索框不包含任务范围控件；范围、状态和排序位于外部快捷栏。
2. 三种范围均可选择并显示当前值，菜单数量来自现有范围投影。
3. 搜索、状态和其他条件继续组合生效，清除全部仍恢复全部任务。
4. 范围筛选、列表与详情联动、空态和负责人显示逻辑保持现有约定。
