# 任务子任务列表、手动创建与删除设计

## 目标

在任务详情中增加稳定可见的“子任务”页签，让用户能够查看、进入和手动创建子任务。同时将任务列表中的“新建任务”改为直接创建空白任务详情，并补齐任务与子任务的删除能力。

本轮创建均为手动创建，不进入 AI 创建对话。新任务创建后立即存在，详情字段继续沿用现有即时保存方式。

## 任务详情页签

任务详情页签固定排列为：

1. 概览。
2. 子任务。
3. 文件。
4. 活动。

“子任务”页签始终显示，并展示直接子任务数量；没有子任务时显示 `0`。页签继续支持现有鼠标点击、左右方向键、Home 和 End 键切换。

## 子任务列表

子任务页采用独立卡片列表，延续现有任务列表的信息层级与视觉语言。

- 页头左侧显示“子任务”和数量摘要。
- 页头右侧提供主操作“新建子任务”。
- 每张卡片展示任务名称、正式状态、负责人和截止时间。
- 点击卡片进入对应子任务详情。
- 列表只展示当前任务的直接子任务，不混入更深层后代。
- 无子任务时展示空状态，并保留“新建子任务”操作。

## 手动创建任务

任务列表中的“新建任务”不再进入 AI 创建对话，而是立即创建一个独立任务并打开其详情。

新任务初始值：

- 名称：`未命名任务`。
- 状态：`待开始`。
- 负责人：当前用户。
- 目标、标签、参与人、计划时间、截止时间、文件和活动为空。
- 不设置父任务和依赖关系。
- 目录位置使用任务列表当前采用的工作区根级任务位置。

创建成功后立即选中新任务并进入详情。用户对名称、目标、负责人、参与人、状态、标签和时间的修改继续即时写入工作区任务状态，不增加额外“保存”按钮。

## 手动创建子任务

点击详情页“新建子任务”后，系统立即创建一个任务并打开其详情。初始字段与独立任务一致，区别如下：

- `parentTaskId` 指向发起创建操作的当前任务。
- 目录位置与父任务保持一致。
- 新任务创建后立即计入父任务的直接子任务数量。
- 详情路径显示父任务与当前子任务关系。

新建任务详情不得注入演示文件、模拟活动、AI 洞察或代码提交。现有演示任务继续使用原有模拟详情。

## 删除入口与确认

任务详情提供删除任务入口。删除动作必须经过明确确认，不支持无确认直接删除。

删除没有子任务的任务时，确认框说明任务将被永久删除且无法撤销，危险按钮文案为“删除任务”。

删除存在后代任务的任务时：

- 递归统计全部后代任务，而不只统计直接子任务。
- 确认框明确展示将被同时删除的后代任务数量。
- 提示文案说明主任务及全部子任务会一并移除且无法撤销。
- 危险按钮使用“删除任务及 N 个子任务”。

取消确认不改变任何数据。确认删除完成后返回任务列表，不自动打开其他任务。

## 数据清理

级联删除一次性完成以下处理：

1. 收集目标任务及其全部后代任务 ID。
2. 从工作区节点中移除这些任务。
3. 从剩余任务的 `dependsOnTaskIds` 中移除所有被删除 ID。
4. 清理被删除任务对应的详情期段覆盖、负责人提议和旧任务快照等本地状态。
5. 清除当前任务选择并展示任务列表。

删除子任务使用相同逻辑；若该子任务还有自己的子任务，也进行递归删除并显示对应数量。

## 组件与状态边界

- `App` 负责创建任务、生成唯一 ID、写入工作区节点、导航，以及执行级联删除和关联状态清理。
- `TaskDetail` 负责页签、子任务列表、创建入口和删除确认界面，通过回调请求创建、打开或删除任务。
- 子任务列表复用 `TaskRelationSummary` 需要的展示字段，不复制完整详情数据。
- 空白任务详情通过明确的空详情构造函数生成，避免复用会注入演示内容的 `createWorkspaceTaskDetail`。
- 现有任务的父子关系仍以 `parentTaskId` 为唯一来源。

## 空状态与异常

- 子任务为空：显示空状态和创建按钮。
- 截止时间为空：卡片显示“未设置”。
- 负责人为空：显示“未分配”；正常手动创建默认不会进入该状态。
- 依赖关系引用已经不存在的任务：删除清理时直接移除该引用。
- 连续快速创建：每次生成独立唯一 ID，不覆盖已有“未命名任务”。
- 删除确认期间数据变化：确认时根据当前工作区状态重新计算删除集合，确保新增后代不会遗留。

## 验证标准

- 所有任务详情均显示“子任务”页签及正确的直接子任务数量。
- 子任务列表信息完整，点击可进入对应详情。
- 任务列表“新建任务”立即创建独立空白任务并进入详情。
- “新建子任务”立即创建带正确父任务关系的空白任务并进入详情。
- 新建任务没有演示文件、模拟活动、AI 洞察或代码提交。
- 编辑新任务字段后，任务列表和再次打开的详情展示最新值。
- 删除叶子任务需要确认，且只删除目标任务。
- 删除带后代的任务明确展示后代数量，并递归删除全部后代。
- 删除后不存在指向被删除任务的依赖引用或遗留本地详情状态。
- 取消删除不会改变任务数据。
- 页签键盘导航、窄屏横向滚动和子任务卡片布局保持可用。
