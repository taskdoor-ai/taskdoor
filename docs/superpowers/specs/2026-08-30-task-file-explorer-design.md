# Task 文件资源管理器改造设计

## 目标

把 Task 详情中的“文件”页从只读文件树改造成可组织、可维护、可查看的任务文件资源管理器。它必须支持多级文件夹、文件夹增删改、文件唯一归属、文件移动、自定义 Icon、版本展示和多格式预览，同时保持现有 Task 内权限与引用语义不变。

## 已确认的产品规则

- 文件夹支持任意层级嵌套。
- 同一文件在当前 Task 中只有一个文件夹归属；移动只改变归属，不复制内容。
- 文件夹只组织文件，不表达任务状态或责任。
- 删除空文件夹可直接确认删除。
- 删除非空文件夹必须选择：将内容移动到上一级后删除，或将整个文件夹及内容归档；默认选择前者。
- 文件夹和文件都支持更换 Icon，不提供自定义颜色。
- 文件根据扩展名获得默认 Icon；手动 Icon 只覆盖视觉表现，不改变格式、打开方式或内容。
- 文件展示当前有效版本号和更新时间。

## 界面结构

采用“A1 精密工作台”双栏布局。

### 左侧：文件结构

- 宽屏下固定约 232px；右侧预览区自适应。
- 顶部依次为标题与数量、上传文件、新建文件夹、任务内搜索。
- 树节点按“文件夹优先、文件其次、同类按名称”稳定排序。
- Chevron 只控制展开或收起；点击名称只选择节点，避免浏览结构时意外切换状态。
- 每一级显示缩进引导线。折叠文件夹的后代不进入 DOM。
- 文件夹节点显示 Icon、名称、子项数和更多菜单；文件节点显示 Icon、名称和更多菜单。
- 选中文件后使用克制的蓝色轨道选中态；长名称单行省略，悬停显示完整名称。
- 文件夹选中时，右侧显示文件夹摘要和直接子项，而不是空白预览。

### 右侧：查看区

- Header 展示 Icon、文件名、格式、当前版本、更新时间和完整文件路径。
- 稳定操作区提供“移动”和“更多”；版本信息始终可见，不藏在菜单中。
- 主区根据文件格式切换查看器。
- 底部保留现有“选中正文并发起有来源对话”能力，仅对可选择文字的查看器启用。
- 没有选中节点时显示引导空状态；无法预览时显示文件信息、格式说明以及打开/下载动作。

### 响应式

- `> 760px`：保持文件树 + 预览双栏。
- `<= 760px`：使用“文件结构 → 文件查看”的分层导航；打开文件后通过顶部返回按钮回到原文件夹和滚动位置。
- 不在窄屏强行压缩双栏，不产生横向滚动。

## 操作设计

### 创建文件夹

- 顶部“新建文件夹”在当前选中文件夹下创建；未选中文件夹时创建在根层。
- 使用小型 Dialog 输入名称，并明确显示创建位置。
- 名称去除首尾空格，同级不允许重名；失败时保留输入并显示具体原因。
- 创建成功后展开父文件夹、选中新文件夹，并进入就地重命名状态。

### 重命名

- 文件夹与文件的更多菜单均提供“重命名”。
- 在树节点内就地编辑；Enter 保存，Escape 取消，失焦时保存合法值或恢复原值。
- 文件重命名默认保留扩展名；修改扩展名时显示格式变化确认。

### 移动和唯一归属

- 文件和文件夹均可通过“移动到…”Dialog 选择目标文件夹。
- 不允许把文件夹移动到自身或任何后代。
- 移动后保持选中状态，自动展开目标路径，并提示新的完整路径。
- 当前版本不以拖拽作为唯一移动方式；可后续增加拖拽，但菜单与键盘路径必须始终可用。

### 删除和归档

- 空文件夹：确认名称后删除。
- 非空文件夹：Dialog 展示子项数量，并让用户选择“内容移到上一级后删除”或“整个文件夹归档”。
- 根层文件夹执行“移到上一级”时，内容移动到 Task 文件根层。
- 文件删除使用单独确认流程；原型中为可恢复删除，并显示撤销 Toast。

### Icon

- 更多菜单包含“更换图标”和“恢复默认”。
- 选择器支持搜索、常用图标和全部图标；复用项目现有 Lucide 图标体系与 Popover/Dialog 视觉语言。
- 文件夹默认 `Folder`；文件默认按格式映射，例如 PDF、表格、Markdown、图片、压缩包和通用文件。
- 自定义 Icon 写入节点的 `iconName`；恢复默认时移除覆盖值。

## 多格式预览

查看器由格式解析器根据扩展名或 MIME 类型选择。文件格式事实与查看器分离，未知格式不得误用文本查看器。

| 格式 | 查看方式 | 版本内能力 |
| --- | --- | --- |
| Markdown (`md`, `mdx`) | 标题、列表、引用、代码块等结构化渲染 | 可选择正文并发起来源对话 |
| 纯文本 (`txt`, `log`, `csv` 文本回退) | 保留换行和等宽内容 | 可选择正文 |
| 表格 (`xlsx`, `xls`, `csv`, `tsv`) | 工作表标签、冻结表头、行列网格和横向滚动 | Demo 使用结构化 Mock 数据，不解析真实二进制 Excel |
| PDF | 分页纸张预览、页码和缩放工具 | Demo 展示可搜索的模拟正文；不新增 PDF 引擎依赖 |
| 图片 (`png`, `jpg`, `jpeg`, `gif`, `webp`, `svg`) | 居中适配、原始尺寸信息、缩放 | 不提供正文选择 |
| 文档 (`doc`, `docx`) | 文档纸张式结构化预览 | Demo 使用提取后的 Mock 正文，不解析真实二进制文件 |
| 其他或未知格式 | 文件 Icon、格式、大小、版本、更新时间与无法预览说明 | 提供打开/下载入口 |

每个查看器都接受统一的 `TaskFileNode` 与版本信息，输出一致的加载、空、错误和不可预览状态。这样可以独立增加新格式，不让文件树承担格式判断。

## 数据模型

在现有 `TaskFileNode` 基础上增加原型所需字段：

```ts
type TaskFileNode = {
  id: string;
  kind: "folder" | "file";
  name: string;
  parentId: string | null;
  updatedAt: string;
  iconName?: string;
  format?: string;
  mimeType?: string;
  sizeLabel?: string;
  version?: number;
  content?: string;
  previewData?: MarkdownPreview | TextPreview | TablePreview | PdfPreview | ImagePreview;
  archived?: boolean;
};
```

- `parentId` 是 Task 内唯一归属真相。
- `version` 是当前有效版本号；这次原型不新增完整版本历史编辑器。
- `previewData` 是 Demo 查看数据，不等同于真实 File 内容存储。
- 数据更新先在 TaskDetail 本地状态完成；不声称已经接入持久化 API、ACL 或审计。

## 组件边界

- `TaskFileExplorer`：组合工具栏、文件树与查看区，持有选择与展开状态。
- `TaskFileTree` / `TaskFileTreeNode`：递归树、键盘导航、行内编辑和节点菜单。
- `TaskFileToolbar`：搜索、上传和创建文件夹入口。
- `TaskFilePreview`：查看 Header、版本元数据和格式路由。
- `TaskFileViewer` 族：Markdown、文本、表格、PDF、图片、未知格式查看器。
- `TaskFileMoveDialog`：目标树与非法目标过滤。
- `TaskFolderDeleteDialog`：非空文件夹处置策略。
- `FileIconPicker`：Icon 搜索、选择和恢复默认。

组件以明确 Props 交换节点和操作回调，避免继续扩大 `TaskDetail.tsx` 的职责。

## 可访问性与性能

- 文件树遵循 Tree 控件语义：单一 Tab 入口；上下键移动；右键展开或进入；左键折叠或返回父级；Home/End 跳转；按名称首字母定位。
- 节点公开 `aria-level`、`aria-expanded`、`aria-selected`、同级位置和集合大小。
- 所有更多菜单、Dialog、确认动作都可用键盘完成并恢复焦点。
- 折叠分支不渲染；当可见节点达到数百项后才考虑虚拟化，本次 Demo 不引入虚拟列表。
- 动效仅用于 120–180ms 的展开与状态过渡，并尊重 `prefers-reduced-motion`。

## 异常与空状态

- 同级重名、非法移动、空名称和扩展名变化都有明确的就地错误。
- 操作后原选择不存在时，优先选择上一级；没有上一级则进入根层空状态。
- 搜索无结果时保留搜索词并提供清除入口。
- 格式无法识别不报通用错误，而进入“暂不支持预览”状态。
- 查看器加载失败只替换右侧查看区，不破坏左侧树和当前路径。

## 测试与验收

- 多级创建、展开、重命名、移动、唯一归属和非法后代移动。
- 空文件夹删除、非空文件夹两种处置方式、撤销文件删除。
- 文件夹与文件 Icon 设置、恢复默认以及格式默认 Icon。
- Markdown、文本、表格、PDF、图片、DOCX 和未知格式分别路由到正确查看器。
- 文件 Header 始终展示版本号，移动与更名不改变版本号。
- 1440px 双栏、760px 边界和 390px 分层导航均无横向溢出。
- Tree 键盘导航、焦点恢复、菜单与 Dialog 的可访问名称可用。
- 保留从文件正文选择内容并发起有来源对话的现有流程。

## 不在本次范围

- 真实文件上传、二进制解析、下载与外部打开接口。
- 完整版本历史、版本恢复、版本 Diff 和多人协同编辑。
- 后端持久化、真实 ACL 变更、审计和团队级文件发布。
- 拖拽移动、批量选择和批量操作。

## 视觉依据

设计参考 21st 的 Ruixen FileTree 与 shadcn/Radix Dropdown Menu，但只借鉴递归节点、行内操作和菜单模式。最终视觉继续使用 AgentDoor 的 Geist 字体、现有设计 Token、克制蓝色选中态、浅灰文件轨道和 Lucide 图标，不直接复制第三方主题。
