# 子任务空状态与字号 Token 设计规格

日期：2026-08-30  
状态：已确认方向，待实现

## 1. 目标

本次改造同时解决两个问题：

1. 子任务为空时，“添加子任务”入口与空状态内容混在虚线框内，信息层级不清晰。
2. 项目中的字号、行高和字重没有完整使用语义 Token，导致按钮和局部组件出现随机字号。

改造后的界面要让“区域操作”与“内容状态”明确分离，并建立可被所有通用组件直接引用的排版契约。

## 2. 子任务区域

### 2.1 信息结构

子任务区域采用统一标题栏：

- 左侧：`子任务 (数量)`。
- 右侧：`添加子任务`按钮。
- 按钮在有无子任务时均保留，避免入口位置随数据状态变化。

空状态虚线框只承载：

- 语义图标；
- 标题“暂无子任务”；
- 说明“需要拆分独立交付时，可从右上角添加。”。

虚线框中不再包含按钮或其他主操作。

### 2.2 布局

```text
子任务 (0)                                      ＋ 添加子任务
┌ - - - - - - - - - - - - - - - - - - - - - - - ┐
│                    [空状态图标]                    │
│                    暂无子任务                      │
│         需要拆分独立交付时，可从右上角添加。         │
└ - - - - - - - - - - - - - - - - - - - - - - - ┘
```

- 标题栏使用 `display: flex`、`justify-content: space-between`、`align-items: center`。
- 空状态内容水平、垂直居中，保持足够呼吸感。
- 窄屏优先保持标题与操作在同一行；仅在极窄宽度下允许自然换行。

### 2.3 交互与可访问性

- 复用现有 `addSubtask` 行为，不改变数据逻辑。
- 按钮使用共享 `Button` 组件，图标为装饰性图标，按钮文字提供完整语义。
- 空状态图标不响应点击。
- 键盘焦点、hover、disabled 继续继承共享按钮行为。

## 3. 语义字号规范

### 3.1 语义层级

| Token 角色 | 字号 / 行高 | 默认字重 | 使用场景 |
| --- | --- | --- | --- |
| Display | 40 / 44 | 650 | 核心数字、极少数展示标题 |
| Title 1 | 28 / 34 | 650 | 页面主标题 |
| Title 2 | 22 / 28 | 650 | 核心区块标题 |
| Title 3 | 18 / 24 | 600 | 面板、卡片组标题 |
| Body | 15 / 24 | 400 | 正文与主要说明 |
| Body Small | 14 / 21 | 400 | 次要正文、紧凑信息 |
| Label | 13 / 18 | 550 | 按钮、筛选器、字段名、标签 |
| Caption | 12 / 18 | 450 | 时间、数量、辅助信息 |
| Code | 12 / 18 | 500 | 等宽数据与代码内容 |

产品交互文字的最小常规字号为 `12px`。低于该值的历史样式视为待迁移债务，不再新增。

### 3.2 Token 结构

在 `styles/agentdoor-tokens.css` 中同时提供字号、行高和字重，避免只引用字号后又局部随机指定另外两项：

```css
--ad-text-label: 13px;
--ad-leading-label: 18px;
--ad-weight-label: 550;
```

所有层级均遵循：

- `--ad-text-{role}`
- `--ad-leading-{role}`
- `--ad-weight-{role}`

控件层另外提供语义别名：

```css
--ad-control-font-size: var(--ad-text-label);
--ad-control-line-height: var(--ad-leading-label);
--ad-control-font-weight: var(--ad-weight-label);
```

控件别名表达“这是一个控件文字”，避免业务组件自行判断应该使用 `label` 还是 `caption`。

### 3.3 使用规则

- 页面和组件不得新增无语义的裸字号。
- 按钮、选择器、筛选器统一引用控件字号 Token。
- 组件尺寸只控制高度和内边距，不再隐式改变文字层级。
- 图标按钮不受文字 Token 影响。
- 本次先迁移共享 `Button` 和子任务区域；历史页面采用渐进迁移，避免一次性产生大范围视觉回归。

## 4. 本次实现边界

### 包含

- 调整子任务标题栏与空状态布局。
- 将“添加子任务”移至标题栏右侧。
- 空状态加入图标、标题和说明。
- 补全排版 Token。
- 让共享按钮文字使用控件 Token。
- 更新现有 AgentDoor 设计系统文档。
- 添加源代码契约与行为测试，覆盖入口位置、空状态纯度和 Token 使用。

### 不包含

- 不重写历史任务数据。
- 不全量迁移所有旧页面的裸字号。
- 不修改新增子任务后的数据行为和展开逻辑。
- 不引入新的按钮变体或新的字体家族。

## 5. 验收标准

1. “添加子任务”位于子任务标题右侧，字号与其他项目级操作一致。
2. 空状态虚线框内不存在可点击按钮，只包含图标、标题和说明。
3. 有子任务时，标题栏右侧仍保留添加入口。
4. `Button` 不再通过 `text-xs` / `text-sm` 随尺寸随机改变文字层级。
5. 字号、行高和字重均能通过语义 Token 引用。
6. 相关测试、类型检查和构建通过。
