# 常驻任务助手实施计划

> **For agentic workers:** 使用 superpowers:subagent-driven-development 执行独立实现子任务；产品规则遵循 agentdoor-task-design。用户要求最小必要验证，不执行双重审查或全量测试。

**Goal:** 在现有原型加入可持续对话、查询汇报、预览并执行增删改的右侧任务助手。

**Architecture:** 助手协议和意图处理独立于 UI；模型输出只形成候选。确定性事务层校验团队、任务快照、成员与关系后复用现有任务创建、删除和恢复存储。App 提供最新任务上下文及单一提交入口，侧栏维护按用户／团队／任务隔离的会话。

**Tech Stack:** React、TypeScript、Zod、Vite middleware、现有 PPIO Responses API、本地存储事务、Node test runner。

## 实现约束

使用当前 `codex/task-creation-v2` 工作区，保留已有未提交改动，不重置或自动提交用户工作。生产授权仍需真实服务端 ACL，本地团队过滤不表述为生产安全实现。接口或网络缺失显示真实错误；不能用演示回复冒充模型输出。后台主动分析、团队参考库和二进制文档解析按需求文档留在后续阶段。
