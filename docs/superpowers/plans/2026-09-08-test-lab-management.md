# TaskDoor 测试平台扩展

**目标：** 在既有独立测试工作台中完成 Skill 版本、模型、人员视角和复杂行业任务的联动管理。

**设计依据：** 仅使用 `skills/agentdoor-task-design/SKILL.md`。主要用户是准备测试上下文、比较不同配置输出的平台维护者。成功证据是配置可持久化、运行使用选中配置且历史不变、切换人员后不可见资料不进入模型。

**实现：** 延用 React、Vite 中间件和原子 JSON 存储。在当前分支内仅修改测试平台相关文件，保留已有未提交工作。

- [x] Skill：保存不可变版本、版本说明、默认版本与回退；步骤可固定版本；排队时冻结实际内容。
- [x] 模型及人员：管理常用模型 ID；运行前选择模型和执行人员；同请求键配置不一致时拒绝；无权访问目标任务在入队前阻止。
- [x] 团队任务：复用字段编辑器，直接编辑人员、任务资料和子任务；文件正文可导入和下载；列表按父子层级展示，动态按时间排列。
- [x] 行业上下文：新增完整制造、零售场景，含跨角色责任、三级任务、文件版本、争议、受限记录及多轮用例。现有存储按 ID 增补，不覆盖用户编辑或历史快照。
- [x] 验收：先增加配置冻结、可见范围和迁移的定向测试；运行测试平台相关测试与构建，浏览器验证关键交互及窄屏，不运行项目全量测试或双重审查。

加载、错误、空状态沿用现有工作台；保存冲突保留草稿，缺失模型连接不显示可运行成功，视角加载期间不展示上一人员数据。运行只在用户点击运行后触发。
