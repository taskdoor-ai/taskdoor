# 文件讨论与动态附件 Demo 实施计划

> 执行：使用 superpowers:subagent-driven-development 分离独立模块；遵循 AGENTS.md 的最小必要验证，不执行全量测试或双重审查。用户已要求更新当前 Demo，保留工作区既有改动。

**目标：** 文件评论确认后保留在文件右侧；动态及回复可以上传／引用附件，附件出现在同一任务文件列表；完善回复、@、编辑删除及本地恢复。

**架构：** 一个按团队与 Task 隔离的本地协作快照，原子保存新增消息、文件位置、文件讨论串和站内提醒记录；既有任务示例作为只读基线，消息修改形成覆盖记录。文件与任务讨论只共享输入和附件组件，文件评论不进入任务动态／活动计数。文件正文沿用版本编辑存储，Lexical 承接文字查看、选区及评论输入。

**技术栈：** React／TypeScript、Lexical、浏览器本地存储、现有 TaskFileNode 和人员目录。Demo 不接外部通知或生产 ACL。

- [x] 存储模块 `src/lib/taskCollaboration.ts`：稳定消息／回复／文件 ID；保存先验证再发布 UI；同请求去重；删除消息保留附件；过期写入拒绝。先在 `server/taskCollaboration.test.ts` 验证上述业务不变量。
- [x] 输入模块 `src/components/discussion/DiscussionComposer.tsx`：Lexical 多行输入、有效人员提及、选择已有文件／上传／拖入／粘贴、提交失败保留草稿、纯附件发布。旧 MentionComposer 留给未迁移入口。
