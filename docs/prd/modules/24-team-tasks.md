# 团队任务

## 1. 目的

查看任务元数据并按权限加入或指定负责人。

## 2. 范围和边界

从账户菜单进入设置，在对应页面处理团队任务；操作权限沿用账号及当前团队权限。

## 3. 详细功能设计

- “团队任务”后显示当前分类筛选结果的总数，包含全部分页；切换分类及指定负责人后同步更新，翻页不改变数量。空结果显示 0，数据未读到时不显示为 0。
- 按标签查看：全部、30 天无活动、待认领、因成员退出而无主、回收站。普通分类排除已删除任务，回收站仅展示已删除任务，时间列显示删除时间，并提供恢复入口；恢复规则见模块 13。任务工作区的回收站入口继续保留。每行展示任务名称、子任务数量、状态、最近活动和负责人。
- 列表分页展示，每页 10 项，底部提供上一页、下一页和当前页数；首页禁用上一页，末页禁用下一页。切换分类回到第一页。
- 最近活动独立成列；负责人显示头像和姓名，无负责人时明确标注。没有子任务时省略子任务数量。
- **指定负责人**：仅无负责人的任务可指定；选择一名团队成员并填写原因，对方不是任务成员时同时加入任务。
- **加入任务**：管理者以填写原因的方式加入任务成员，任务成员会收到通知；退出任务后记录仍保留。
- 不提供归档操作和批量勾选；指定负责人、加入任务的原因均写入行为日志。

## 4. 功能验收标准

- 页面按本人身份展示可访问的数据与操作，无权限时不能执行写入。
- 页面结果与上述规则一致；失败不得显示成功，保留可重试的信息。
