# 成员

## 1. 目的

快速找到当前团队成员，并查看及管理人员信息。

## 2. 范围和边界

从账户菜单进入设置，在对应页面处理成员；操作权限沿用账号及当前团队权限。

## 3. 详细功能设计

查看当前团队成员及身份，并根据本人权限邀请成员、设置或取消管理员、移除成员。

- 团队仅有一名拥有者，成员权限按[权限](15-permissions-errors-nfr.md)执行，拥有者不能被其他成员移除。
- 名单分为在职和已停用；在职包含已加入成员与待加入人员，已停用包含被管理员拒绝的加入申请记录。已停用行可直接重新邀请，权限及处理结果见[重复邀请与失效](09-member-collaboration.md#重复邀请与失效)。
- 邀请绑定邮箱、团队及角色，确认加入后建立成员关系；完整流程见[成员、邀请与任务分工](09-member-collaboration.md)。
- 移除或本人退出时处理未完成任务交接，完整规则见[成员退出与移除](14-membership-account-exit.md)。

### 成员搜索

在当前团队、当前在职或已停用分类中，按操作者有权查看的姓名、邮箱或职责的当前显示文本搜索。输入后立即筛选，忽略查询首尾空白及英文字母大小写，任一可见字段包含查询即可匹配；清除查询恢复该分类完整名单。搜索覆盖当前分类的全部可访问记录，先筛选再分页，不限于已加载的页面。无权查看的邮箱、职责等字段不参与匹配，不能通过搜索结果探测其内容。搜索不改变人员原有顺序、权限及邀请或编辑操作。

切换在职／已停用时保留查询并在新分类内筛选，切换团队时清空查询。分类内没有人员时显示原空状态；有人员但搜索无匹配时说明未找到匹配成员，并允许清除查询。


## 4. 功能验收标准

- 页面按本人身份展示可访问的数据与操作，无权限时不能执行写入。
- 姓名、邮箱或职责中任一有权查看的当前显示字段包含查询即展示对应成员，带首尾空白或不同英文大小写的同一查询得到相同结果。筛选只作用于当前团队和当前分类的全部可访问记录，先筛选再分页，未加载页中的匹配成员同样可找到；结果保持原顺序。
- 无权查看的字段不影响搜索结果；普通成员不能通过停用人员的隐藏邮箱或职责命中记录，原字段权限不因搜索扩大。
- 输入及清除立即更新名单；切换在职／已停用保留查询，切换团队清空。分类没有人员与搜索无匹配显示不同提示，搜索后原有邀请及编辑操作按权限可用。
- 页面结果与上述规则一致；失败不得显示成功，保留可重试的信息。
