# 任务列表

## 1. 目的

任务列表是用户查找和进入任务的主要入口。它需要让用户快速看清近期任务、缩小查找范围，并把需要持续关注的任务固定在列表顶部，减少重复搜索。

## 2. 范围和边界

本模块覆盖任务列表页中的页面结构、搜索、筛选、排序、加载、打开任务和置顶管理。任务正文、任务内讨论、文件管理以及任务创建和编辑流程由各自模块定义；本模块只说明它们在列表中的入口和结果反馈。

## 3. 详细功能设计

### 3.1 页面结构

任务列表依次包含标题与新建入口、搜索行、快捷筛选与排序行、置顶区和普通任务列表。范围入口放在搜索框外，不在搜索框内嵌下拉或胶囊。系统先得到搜索与筛选结果，再按是否置顶分区；同一个任务只出现一次。没有置顶结果时不展示空置顶区，不按标签分组。

```text
任务                                      ＋
[ 搜索图标 输入                         ] [筛选]
[范围图标 全部任务 ▾] [状态图标 全部状态 ▾]   [上下箭头 最近更新 ▾]
置顶（有置顶结果时显示）
任务列表
```

新建与筛选按钮大小一致，左右边缘上下对齐；输入框与筛选按钮等高。桌面控件为 36px，窄屏为 44px，共用右侧边距。两个快捷筛选在左侧紧凑分组，排序独立靠右，通过留白区分用途，不增加分隔线。

### 3.2 搜索、筛选与排序

#### 关键词搜索

搜索框保留前置搜索图标，提示文案仅为“输入”，无障碍名称为“搜索任务列表”。空输入时不显示清除叉；有内容时显示，点击只清空关键词，不清除范围、状态、标签或日期条件。Escape 同样清空关键词。关键词按任务名称匹配，输入后更新结果并将列表滚动位置回到顶部。

#### 任务范围与状态快捷筛选

默认范围为“全部任务”。范围菜单单选，包含“全部任务／我负责的／我参与的”；我负责的按当前用户的正式负责人关系匹配，我参与的按正式参与人关系匹配，创建者身份不能代替这两种关系。两个个人范围可以包含同一任务，但一次只选择一种范围。“全部任务”仅解除范围限制，保留关键词与其他条件。

范围入口图标随当前选项变化：全部任务用列表、我负责的用单人、我参与的用多人。菜单右侧数量表示在现有关键词、状态、标签和日期条件下，分别切换至该范围可得到的任务数；不能简单相加。菜单文字 13px，数量 12px、常规字重、辅助色、等宽数字并右对齐。选中项使用浅蓝圆角底色与蓝色勾选，文字和数量保留原有颜色，与状态菜单选中样式一致。

状态菜单支持多选；无条件时显示“全部状态”，单选显示状态名称，多选显示“N 个状态”。选择“全部状态”只清除状态条件，不清除其他维度。状态菜单与高级筛选共享同一组条件；同维度多选取并集，不同维度取交集。任务范围或状态限定后，其入口图标与文字同步高亮；排序入口保持中性色。

#### 排序

默认按“最近更新”倒序，也可切换“最新创建”倒序。外部入口保留上下箭头图标与当前排序名称；下拉选项只显示文字和选中勾选，不重复添加波形、日历等图标。排序只改变结果顺序，保留全部搜索与筛选条件。

#### 高级筛选与清除

高级筛选只提供状态、标签、截止日期、创建日期，不再重复提供任务范围或负责人、参与人、创建人入口。标签可选择具体标签或“未打标签”。分类行展示图标、名称、已选摘要和统一右对齐的展开箭头；不在分类行右侧添加清除叉。进入分类后可修改选项，并通过详情标题旁的“清除”清空该维度。

已选条件只在弹层底部以紧凑条件标签显示，每个条件带独立清除叉；“清除全部”位于同一底部条件区的右侧，不在顶部或独立底栏重复出现。移除单个条件只影响该条件；清除全部恢复全部任务范围并移除状态、标签及日期条件，保留关键词和排序。条件全部清除后，该底部区域消失。

收起弹层后，筛选按钮显示已选状态、标签和日期等条件的总数；任务范围与关键词不计入，状态快捷筛选不重复计数。没有条件时不显示数字徽标。弹层随内容收缩，不展示结果总数或额外的关闭叉。

#### 列表与详情联动、空态与键盘

切换任务范围后，桌面详情选择新结果集首条任务；修改其他筛选或关键词时，当前任务仍匹配则保持，否则选择首条。空结果时列表展示“没有匹配的任务”，右侧不保留筛选外详情。“查看全部任务”同时清空关键词和筛选以恢复结果；团队尚无任务时提供创建入口。

菜单支持方向键、Enter、Escape 和焦点返回；移除条件后焦点转到邻近可操作项，最后一个条件移除后返回筛选分类。窄屏快捷栏可换行，列表与详情通过返回操作切换，触控入口至少 44px。生产数据加载、失败、无权限或过期时应明确提示，不把未知数量显示为真实的 0，也不泄露不可见任务。

### 3.3 任务列表区

**展示内容。** 任务行显示状态图标、单行任务标题和负责人头像；“我负责的”范围隐藏重复负责人。标签只用于筛选，更新时间和创建时间用于排序及无障碍说明，不在任务行常驻展示。长标题提供完整名称提示。

**可用操作。** 点击任务项打开任务；悬停任务项时，右侧显示图钉和更多操作。键盘用户在任务项获得焦点时看到相同操作，触屏用户通过任务项右侧的常驻更多入口访问这些操作。

**操作步骤与结果。** 用户打开任务后在同一工作区进入对应详情，返回时恢复此前的搜索、筛选、排序和滚动位置。用户点击更多操作后，在原任务项附近打开菜单；完成操作后菜单关闭，并在原位置给出结果反馈。

| 展示内容 | 可用操作 | 操作步骤与结果 | 必要说明 |
| --- | --- | --- | --- |
| 完整任务项 | 打开任务 | 点击任务项或按回车进入任务；返回后恢复列表上下文。 | 主点击区域不与右侧快捷操作重叠。 |
| 右侧图钉 | 置顶、取消置顶 | 点击后任务在置顶区和普通任务区之间移动。 | 悬停或键盘聚焦时显示；触屏从更多菜单进入。 |
| 右侧更多入口 | 查看其他可用操作 | 打开贴近当前任务项的菜单，执行后就地反馈。 | 菜单内容由任务权限决定。 |

**排序与分页或加载。** 初版采用连续加载：首次只加载一批结果，接近列表底部时继续加载下一批。排序对全部匹配结果生效，而不是只作用于已加载内容。加载失败时保留当前内容，并在列表底部提供明确的重试入口；重新搜索或筛选会取消尚未完成的旧请求。

### 3.4 置顶区

**展示内容。** 置顶区位于普通任务之前，显示当前搜索和筛选结果中已置顶的任务。区标题为“置顶”；置顶任务仍按当前排序规则排列，不再出现在普通任务区。

**可用操作。** 用户悬停或用键盘聚焦任务项时，可点击右侧图钉置顶或取消置顶。已置顶状态使用实心或高亮图钉，并提供可被辅助技术读取的状态名称。

**操作步骤与结果。** 点击未置顶任务的图钉后，任务立即移动到置顶区，并显示短暂成功反馈；点击已置顶任务的图钉后，任务回到普通任务区的正确排序位置。请求失败时任务恢复原位置和原状态，并提示用户重试。置顶是用户个人偏好，不改变任务本身，也不影响其他用户看到的列表。

## 4. 验收标准

- 输入框与筛选按钮等高，新建与筛选按钮左右边缘上下对齐；窄屏满足触控高度。
- 搜索提示为“输入”；空输入无叉，有内容可清除，清除关键词不影响筛选。
- 范围位于搜索框外，与状态在左侧成组，排序在右；三种范围图标与语义对应。
- 范围为单选、状态为多选，范围菜单数量跟随其他条件；范围和状态的选中项均为浅蓝底色、蓝色勾选。
- 排序入口保留上下箭头，下拉选项无额外图标；切换排序保留筛选与关键词。
- 高级筛选分类无清除叉，所有展开箭头右对齐；单项清除与清除全部位于底部条件区，“清除全部”保留关键词和排序。
- 收起高级筛选时仅显示条件数，范围与关键词不计入、状态只计一次；全部清除后隐藏条件区与数字徽标。
- 切换范围与筛选后详情遵循结果集，空结果不保留旧详情；“查看全部任务”可恢复列表。

- 搜索、筛选和排序后，置顶区与普通任务区共同构成完整结果，且不存在重复任务。
- 没有置顶结果时不显示空置顶区；出现首个置顶结果后，该区域位于普通任务区上方。
- 鼠标、键盘和触屏用户都能访问打开任务、置顶、取消置顶和更多操作。
- 置顶或取消置顶成功后，任务立即移动到正确分区；失败后恢复原状态并提供可理解的反馈。
- 连续加载失败不会清空已加载任务，列表底部提供可执行的重试入口。
- 从任务页面返回列表时，搜索、筛选、排序和滚动位置保持不变。
