# 任务列表

## 1. 目的

快速找到并进入需要处理的任务。

## 2. 范围和边界

包含搜索、范围、状态、标签、日期、排序、个人置顶与任务侧栏的宽度及收起偏好。

## 3. 详细功能设计

### 3.1 查找任务

任务侧栏从搜索与筛选区域开始，任务创建使用[工作区顶栏入口](04-workspace-navigation.md)。

| 操作 | 选项 | 结果 |
| --- | --- | --- |
| **任务范围** | 全部任务／我负责的／我参与的 | “我负责的”只显示当前用户为负责人的任务；“我参与的”显示当前用户为参与者的任务。 |
| **任务状态** | 进行中／已阻塞／已完成／已取消 | 支持多选；选择“全部状态”清除状态条件。 |
| **任务排序** | 最近更新／最新创建 | 默认将未完成任务排在已完成任务之前，两组内部按最近更新时间倒序；切换为最新创建后仅按创建时间倒序。 |

- 范围、状态、名称、标签和日期按交集筛选；排序只改变结果顺序。切换任一条件时保留其他条件，并立即更新结果和数量。
- 日期按团队时区解释；无结果时可清除筛选条件。

状态菜单显示全部候选任务数与各状态任务数，帮助用户在切换前判断结果范围。统计保留当前任务范围、搜索及其他筛选条件，忽略当前状态条件；选择状态后仍可查看其他状态的数量。已选项继续显示勾选，空结果明确显示 0。

**列表与详情同步**

- 用户主动打开搜索或筛选结果中的任务时，右侧展示该任务；当前选择不受是否为第一条影响。
- 切换团队、任务范围，或调整搜索、状态、标签、日期筛选后，当前任务仍在结果中则保持；仅没有选择或当前任务不匹配时打开结果第一条，按列表实际顺序选择，置顶任务优先。无结果时清空详情。
- 普通任务数据刷新或仅调整排序时，同样保留仍匹配的当前选择，并沿用上述兜底规则。
- 搜索或筛选触发的自动选择保留当前控件焦点，不打断连续输入；用户手动打开任务时沿用既有导航焦点规则。
- 列表选中项与右侧详情属于同一结果集，不保留筛选外详情或对应提示横幅。未提交内容仍归原任务，按原编辑规则处理，不带到新任务。
- 窄屏在列表中调整搜索或筛选时停留在列表，由用户主动打开详情。列表与详情的空状态说明简短清晰，指引下一步。

从面包屑或关联任务打开详情后，列表自动将选中任务滚动到可见位置；已在可见区域则保持位置。搜索与筛选不因此被清除，选中结果仍遵循上述规则。

### 3.2 置顶任务

用户可将任务置顶。置顶任务显示在列表顶部的“置顶”区域；取消置顶后回到普通任务列表。置顶任务只出现一次，仍受搜索和筛选约束。最近更新模式在置顶与普通区域内分别执行已完成后置，置顶区域始终在普通区域之前；已取消任务沿用更新时间排序。重新打开已完成任务后，按当前状态重新归组。


### 3.3 快速操作

任务行菜单支持标记完成，沿用[任务详情](08-task-detail.md)的状态权限及独立完成规则。状态图标与菜单选项沿用[任务详情](08-task-detail.md)的视觉规则。

### 3.4 侧栏宽度与收起

桌面任务侧栏默认展开，可在分界线两侧抓取边缘拖动柄，或使用键盘调整宽度。正常调整范围为 260px 至当前有效最大宽度；最大宽度取 520px 与任务工作区可用宽度 45% 向下取整的较小值。拖动、键盘调宽、宽度显示、无障碍范围及本次保存的调宽结果使用同一有效边界。展开态不显示收起图标；向内继续拖动边缘可收起整块列表，键盘聚焦拖动柄后按 Home 同样可完全收起。详情随之使用释放的空间。

向左正常拖动时，侧栏先停在 260px 最小宽度；继续向左时视觉宽度仍保持 260px，形成边界阻力。到达最小宽度后再向左至少拖动 80px，松手才吸附至完全收起；额外拖动不足 80px 时，松手仍保持 260px，不进入收起态。向右拖动在当前有效最大宽度停止。正常调整范围内拖动直接跟手，松手收起时承接当前视觉位置，列表宽度恢复与整栏向左滑出同步连续完成，详情同时获得空间；再次展开从左侧连续移入。切换不出现松手后先跳变一次、再继续收起的二段效果。开启减少动态效果时立即完成切换。

收起态仅保留用于展开任务列表的侧栏图标，不显示常驻操作文案。悬停或键盘聚焦提示“展开任务列表”，图标具有完整的无障碍名称；悬停不弹出侧栏。点击图标或通过键盘激活后恢复列表。

再次展开恢复此前展开宽度。搜索、筛选、排序、当前任务、列表滚动位置及详情中未保存的编辑、讨论草稿和文件选择均保留；收起不触发保存、提交或任务切换。宽度和收起状态保留为本设备偏好。收起后的隐藏控件不进入键盘顺序，焦点不会留在不可见区域。

窄屏沿用列表与详情单栏切换，进入详情后可返回列表；桌面收起偏好不会使窄屏列表不可访问。


## 4. 功能验收标准

- 可组合选择“我负责的”、一个或多个任务状态及排序方式；结果、数量和选中状态同步更新。
- 状态菜单数量随范围、搜索、标签和日期条件更新，当前状态条件不影响数量；全部状态数等于同一候选集合的总数，空集合和零匹配状态显示 0。
- 最近更新模式中，即使已完成任务的更新时间更近，也排在同一区域的未完成任务之后；两组内部保留更新时间倒序，未知时间沿既有兜底规则。最新创建只按创建时间排序，已取消任务不被当作已完成后置。
- 排序不清除范围、状态、搜索及高级筛选条件，也不改变任务数据。
- 在搜索或筛选结果中手动打开非第一条任务，详情展示所选任务；再次调整条件后，该任务仍匹配则保持选中。
- 没有选择或原选择已不匹配时，详情才打开包含置顶区域的实际结果第一条；无结果时清空详情，未提交字段不转移给新任务。
- 仅刷新任务数据或调整排序，匹配任务仍保持选中；窄屏在列表筛选后不自动进入详情。
- 连续输入搜索词或用键盘调整筛选时，详情更新不使焦点离开正在操作的控件；手动打开任务后沿用既有导航焦点规则。
- 置顶仅影响本人且不绕过筛选。
- 分界线两侧均能抓取拖动柄；正常左拖停在 260px，继续左拖时宽度仍为 260px。额外不足 80px 松手保留最小宽度，额外达到 80px 松手才完全收起。
- 向右拖动不超过 520px 与任务工作区可用宽度 45% 向下取整的较小值；拖动、键盘调宽、宽度显示、无障碍范围及保存的本次调宽结果使用同一有效边界。
- 展开态没有收起图标；达到额外左拖阈值后松手或聚焦拖动柄按 Home 均可完全收起。收起态的侧栏图标可通过点击、Enter 或 Space 恢复此前展开宽度。
- 拖动松手后宽度和滑出位置连续衔接，不先跳变后再次收起；切换过程支持连续操作，减少动态效果时无过渡动画。
- 收起再展开后，搜索、筛选、排序、当前任务、列表滚动位置、详情编辑及协作草稿保持；刷新恢复本设备侧栏偏好。
- 展开图标无常驻文案，悬停和键盘聚焦显示展开提示且不会弹出侧栏；收起区域不能被 Tab 聚焦，收起后焦点处于可见控件。窄屏可在列表与详情之间切换，不受桌面收起状态阻断。
