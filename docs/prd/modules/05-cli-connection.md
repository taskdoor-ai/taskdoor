# Agent 与 CLI、MCP 连接

## 1. 目的

让用户选择适合自己工具与工作流程的接入方式，在 AI 工具或自动化流程中继续处理同一个任务。

## 2. 范围和边界

支持 CLI 安装与登录授权、MCP 配置与浏览器授权或个人访问令牌认证，以及任务上下文读取与业务操作；两种方式共享连接 AI 入口，沿用本人及凭据权限。程序通过 API 接入的入口由个人访问令牌管理承接。

## 3. 详细功能设计

**命令设计预留**：帮助文档中的常用命令只列出 CLI 已提供的账号与登录状态、工作空间、任务列表与详情、无浏览器设备登录和退出登录命令；其余业务能力的命令参数、返回结果与异常处理待 CLI／MCP 整体结构确定后补充。

### 3.1 连接流程

1. 打开“连接 AI”，根据能力范围、运行环境与接入条件选择 **CLI 或 MCP**，默认选择 CLI。
2. 选择所用 AI 工具，复制安装配置提示词或在工具中打开，按相应指南完成配置与授权。
3. 在任务或讨论中选择 AI 工具时，主按钮打开最近使用的工具，下拉菜单用于切换；核对带入的任务上下文，在所选工具中继续工作。

![连接方式选择与 CLI 安装引导。](../assets/cli-connection/connection-options-zh.png)

*FIG-CLI-009 · 连接方式选择与 CLI 安装引导。*

#### 连接方式选择

连接 AI 使用 CLI、MCP 两个简洁标签，CLI 的推荐理由在分支说明中表达。当前分支通过对应说明引导用户完成配置与授权；产品和所选 AI 工具的连接标识帮助用户确认连接对象。

| 方式 | 能力范围 | 适用场景 | 接入条件 |
| --- | --- | --- | --- |
| CLI | 与 API 接口和能力一致，提供完整能力 | 本地 Agent、脚本编排和复杂批量操作；本地 Agent 优先推荐 | 在本地或运行环境安装，Agent 能执行命令 |
| MCP | 从完整 API 中精选部分工具，覆盖常用操作 | 支持 MCP 的 AI 客户端，通过工具调用完成常用任务操作 | 客户端支持 MCP，按指南配置后授权 |

推荐依据是工具兼容性、运行环境和所需操作范围。帮助文档补充能力范围和使用示例。

个人访问令牌管理作为 CLI 引导中的辅助入口，承接程序、远程服务或自动化平台的 API 接入需求；进入后可管理凭据并查阅 API 文档。

#### MCP 连接

CLI 与 MCP 共用产品选择、安装配置提示词、复制及在工具中打开的布局。MCP 提示词指向当前部署的 `documents/skills/taskdoor-mcp/SKILL.md`，由所选工具按指南协助配置。支持浏览器 OAuth 授权的客户端优先通过浏览器登录授权；不支持时可使用个人访问令牌，由用户在客户端自行填入。指南使用连接页提供的服务地址，不固定部署域名。页面不展示真实令牌，连接成功以客户端实际结果为准。

MCP 分支先说明精选常用工具，能力范围小于 CLI，以减少上下文负担，让 AI 调用更聚焦；再说明适合在 AI 对话中查任务、看进展和更新信息，以及授权登录或个人访问令牌访问。同段提供“个人访问令牌”入口，在新标签页直接打开个人设置的访问令牌页面，保留原连接页面。

CLI 与 MCP 底部均提示登录时在浏览器中确认即可。“帮助中心”仅显示普通文字，不提供跳转。

![MCP 使用场景、精选工具范围与授权方式，保留个人访问令牌入口。](../assets/cli-connection/mcp-selection-guide-zh.png)

*FIG-CLI-011 · MCP 使用场景与授权方式。*

#### 任务与讨论上下文

- 任务入口带入任务 ID、名称、状态，以及已填写的任务目标、完成标准、负责人和截止时间；完成标准逐项编号，空目标或空标准省略，不附带参与人、标签或父任务详情。
- 讨论入口带入任务 ID、任务名称、已填写的任务目标与完成标准、当前记录的讨论 ID、作者和已保存的发布时间，以及当前记录内容；回复也使用自身的讨论 ID 获取信息，不另带回复 ID。回复草稿带入草稿内容，并明确未发送。
- 不预先带入整串回复或附件内容。工具按用户要求，通过 TaskDoor CLI 按 ID 获取最新详情，访问仍遵循用户权限。
- 带入内容是待分析材料，不自动发送、发布或写回，不预设用户要完成的操作。

#### 连接 AI 页面

- 每个工具使用同一条安装提示词，内容指向当前部署的 CLI 安装文档；可直接复制，或点击“在 {工具} 中打开”。
- “在 {工具} 中打开”先复制提示词，再尝试唤起该工具并带入提示词，不代为发送。结果如实提示：复制失败时不尝试打开；浏览器未能打开时提示手动粘贴；已尝试打开时说明无法确认客户端是否启动。
- 登录只授权用户本人账号，按其在各工作空间的权限访问；工作空间在后续命令中指定，工作空间参数不改变登录授权。
- TaskDoor 看不到用户本机的客户端，没有连接回执时不显示“已连接”或“未连接”。

常用 CLI 命令通过帮助文档查阅，连接页面不展开命令示例列表。

### 3.2 能力与权限

- 授权后，CLI 与 API 覆盖用户在界面中可执行的业务能力，包括读取、对话规划与确认创建、维护任务人员和状态、**人工确认**标准、讨论、文件版本及删除。
- Agent 或程序代表授权用户执行，不因接入方式增加或扩大权限。
- 具体能力以[权限、异常与质量要求](15-permissions-errors-nfr.md)为准，设备授权可撤销。

- 普通操作由用户命令执行，不增加“重要写入”专属审批。
- 创建仍须确认完整方案。
- 任务／文件删除同样先返回影响预览，再以明确确认执行，范围变化重新确认。
- 命令返回真实结果，最新覆盖、**失败**与同次重试规则与 Web 相同。
- 自动 AI 分析只能更新评估，不能借 CLI 自动改变用户状态。

### 3.3 访问令牌

个人访问令牌的创建、范围、有效期和删除规则见设置分组的[访问令牌](21-access-tokens.md)。

## 4. 功能验收标准

- 同一用户在 Web 可操作的业务均有 CLI 路径，普通参与者从两端均不能删除任务，负责人可确认后删除。
- CLI 与 Web 修改同一字段以后成功保存者为准，不影响其他字段；两端重读同一任务与文件版本。
- 删除未确认或范围变化时不能执行；撤销设备或团队权限后旧凭据不能继续读写。
- 连接 AI 页面“在 {工具} 中打开”复制失败时不唤起工具；唤起成功或失败均如实提示，没有连接回执时不显示连接状态。
- CLI 与 MCP 底部“帮助中心”均为普通文字，不触发导航；个人访问令牌入口保持可用。
- 访问令牌只对本人可见；名称为空、未选操作范围、指定团队时未选团队、限定任务时未选任务或有效期超过 365 天时不能创建；令牌值只在创建成功时显示一次；删除后立即失效。
- 指定多个团队时不能限定任务；换选团队会清空已选任务。

- 连接入口可以直接选择 CLI 或 MCP，默认显示 CLI 引导，切换后只显示对应接入步骤。
- 能力说明符合 3.1 的对照规则，鉴权说明不将 CLI 与 MCP 的稳定性差异作为推荐依据。
- CLI、MCP 标签均只显示方式名称；选择 CLI 后可以在分支说明中理解推荐依据，各分支内容与自身能力和接入流程相符。
- CLI 引导中的个人访问令牌入口可进入对应设置页面，API 文档可从令牌管理中查阅；两种连接方式保留工具选择、复制提示词及在工具中打开。
