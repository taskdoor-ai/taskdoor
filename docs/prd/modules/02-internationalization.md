# 海外优先与多语言

## 1. 目的

优先提供英文体验，同时支持简体中文。

## 2. 范围和边界

主要界面已本地化；业务原文独立保存，真实 AI 输出语言及跨设备偏好待接入。

## 3. 详细功能设计

### 3.1 切换语言

认证页无语言入口，沿用偏好、默认英文。登录后：账户菜单 → English／简体中文；更新界面，保留任务与草稿，全流程术语一致。

### 3.2 内容呈现

示例可本地化，用户原文不改写；讨论标记译文并提供原文入口，文件保持原文。

### 3.3 自动翻译协作内容（本地演示）

语言子菜单的“自动翻译协作内容”默认开启，按设备保存：开 → 显示已有译文；关 → 任务字段与讨论恢复原文，界面语言不变。讨论可逐条查看原文／译文；任务更多菜单可切换原文。标题、目标、标准和讨论编辑均用原文。

当前仅匹配本地示例、不外发；无译文则保留原文并提示。实时翻译、权限校验、按语言与原文版本缓存、加载及重试待接入。翻译不得改变金额、币种、身份或引用。

## 4. 验收标准

切换语言不改变任务事实、人员关系和日期含义；缺译文不能冒充已翻译。
