# 账号校验细则

本页供研发和测试查阅，主流程见[账号与个人资料](../modules/02-account-identity.md)。

## 1. 输入与提示

- **注册字段**：邮箱、密码、验证码；同页获取验证码并提交。
- **密码**：至少 8 位；框内提示“密码（至少 8 位）”。
- **验证码**：6 位数字；框内提示“邮箱验证码”，不展示示例码。
- **展示**：输入文字和占位提示使用 16px；Google 入口位于邮箱表单上方。
- **字段错误**：就地提示，修改后清除；保留邮箱和合理输入，不持久化明文密码。
- **首次设置**：注册页不收名称、团队名称或头像；注册成功后，自行注册设置个人和团队名称，受邀注册只设置个人名称。

## 2. 邮箱注册验证

1. 请求验证码，发送中显示状态并禁用重复操作。
2. 提交时显示“正在验证并创建账号”。
3. 服务端校验资料、验证码及邮箱是否已注册。
4. 验证通过后，一次完成账号创建和验证码消费。

**有效期与次数**

| 项目 | 规则 |
| --- | --- |
| 有效期 | 服务端生成起 **10 分钟**；达到到期时间即失效。 |
| 重发间隔 | **60 秒**。 |
| 错误次数 | 单码最多 **5 次**；第 5 次错误后作废。 |
| 重发成功 | 新码生效，旧码失效。 |
| 重发失败 | 仍在有效期内的旧码继续有效。 |
| 修改邮箱 | 旧邮箱验证码不能用于新邮箱。 |
| 绑定范围 | 验证码绑定邮箱、用途及本次请求；不同用途不能混用。 |

**异常处理**

- 发送失败不显示发送成功；错误或过期可重发，保留邮箱和密码输入。
- 账户及来源限流由服务端执行，返回可重试时间；客户端倒计时不作为验证依据。
- 有效码只能成功使用一次；重复请求或结果未知时查询原操作，不重复建账号。
- 发码或前端校验不创建账号、团队或成员关系；验证前无账号会话。
- 已注册邮箱引导登录或“忘记密码”，不能创建第二个账号。
- 刷新后可重新发码，不恢复未经验证的状态。

## 3. 忘记密码与 Google 用户设置密码

**适用对象**：已有邮箱密码的用户，以及尚未设置 TaskDoor 密码的 Google 用户。

1. 输入原账号邮箱，获取密码恢复验证码。
2. 验证通过后设置至少 8 位的 TaskDoor 密码。
3. 保存到**原账号**，返回登录页。
4. 使用同一邮箱和新密码登录。

- Google 注册时无需 TaskDoor 密码；首次设置密码复用此流程。
- 未验证邮箱、验证失败或账号不存在时，不能设置密码或创建账号。
- 密码更新保留 Google 身份、个人资料、团队、任务及当前邀请。
- 密码恢复验证码与注册、绑定验证按用途隔离，不能互相代用。

## 4. Google 及账号关联

- 新 Google 身份验证成功后创建一次账号；已关联身份进入原账号。
- 取消、无效返回或无法取得可信已验证邮箱时，不创建账号。
- 同邮箱已有账号时，验证原账号后确认关联；关联身份已属于其他账号时拒绝，保留原关系。
- 邮箱密码与 Google 关联后使用**同一 account ID**，不复制或迁移团队、任务。
- 本期不支持解绑或更换 Google 身份，也不支持更换账号邮箱。

## 5. 邀请、保存与可访问性

- 注册、登录、Google 返回及密码恢复全程保留邀请；邮箱不符或邀请失效不能加入。
- 认证成功后仍须确认加入；退出登录不删除团队和任务。
- 保存失败或结果未知可重试，操作结果以服务端为准。
- 移动端单列；验证码支持整段粘贴和系统自动填充。
- 键盘可访问所有字段和按钮；错误关联字段，焦点定位到首个错误。
