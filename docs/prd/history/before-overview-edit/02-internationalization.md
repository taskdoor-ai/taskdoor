# 海外优先与多语言

## 1. 目的

海外团队首次进入 TaskDoor 时，应能用英文理解并完成任务创建、分配、协作和结果确认。中文用户可切换到简体中文。同一团队的不同成员可以使用不同界面语言，任务事实保持一致。

产品围绕一条主线表达：明确目标，安排负责人和参与人，协作推进，凭依据确认结果。AI 提供建议和预测，不替代成员决定，不因本地化新增仪表盘、导航层级或另一套产品。

## 2. 范围和边界

已确认方向：海外市场优先，首批支持英文和中文。本模块确定界面、格式化、内容边界、AI 语言与迁移要求；语言默认值、偏好存储位置为本次采用的实现约定。

当前实现覆盖全局语言基础层、工作区主要控件、账户菜单语言入口、登录注册与找回密码、邀请和团队创建、任务创建主要流程、任务详情主要字段与讨论控件。内置演示任务的标题、目标、完成标准、常规讨论及核心达人任务讨论提供英文展示，创建流程的七组示例及新生成的示例方案按当前语言输出。活动页与设置主要控件已接入双语目录；任务进度图表与内置进度依据已补充双语；其他高级分析、部分文件正文仍有历史中文内容，真实 AI 服务端语言协议尚未接通；不能把当前原型作为完整海外可发布产品。

任务标题、目标、讨论、文件、姓名、团队名和用户标签属于用户内容，原文保留。切换语言不翻译、不覆盖、不重新生成这些内容；演示数据也不能覆盖用户已编辑内容。开发文档、历史演示页、测试实验室和 PRD 阅读页本轮不要求翻译，但不得作为英文主流程的默认入口。

本模块不新增支付、税务、地域托管或合规能力；海外优先不代表这些能力已实现。

## 3. 详细功能设计

### 全局语言与入口

语言使用 `en` 和 `zh-CN`。首次使用默认英文；用户选择优先于默认值，不根据 IP 猜测语言。工作区头像账户下拉菜单内提供 Language / 语言子菜单，顶部不再单独占位，选项始终显示自称 English、简体中文。键盘可操作。选择后在原页面切换，保留当前任务、筛选、草稿和未保存输入。

当前原型在浏览器保存设备级偏好，刷新后恢复；存储受限时仍在本次会话生效，其他标签页可同步。未来接入真实账户后，优先级为本次选择、账户偏好、默认英文；不把设备偏好伪装成已经跨设备同步。登录、注册、找回密码和邀请页面在品牌区域提供语言选择，切换保留表单输入。

文档语言标记、页面标题、可访问名称、提示、空态、加载、失败及权限提示均纳入词条目录。新增词条使用稳定语义键，不能以中文原文作为业务键。中英文词条键和插值参数必须一致，翻译缺失回退英文；用户插值按文本渲染，不接受翻译字符串中的 HTML。

### 术语与数据模型

统一术语：任务 Task，负责人 Owner，参与人 Collaborator，目标 Goal，子任务 Subtask，前置依赖 Dependency，完成标准 Acceptance criteria，当前情况 Current situation，下一步建议 Next steps。界面按完整句翻译，不能按中文字序拼接多个片段。

术语含义与使用边界见[中英文术语表](../../i18n-terminology.md)。Owner 表示对结果负责的人；Collaborator 表示参与协作的人。Acceptance criteria 是当前任务可核验的完成条件，不意味着新增审批步骤，也不等同于团队通用的 Definition of done。Dependencies 只表达前置依赖，不表达父子归属。此次统一为措辞修正，任务模型、流程和权限不变。

现有任务状态保存为中文字符串，当前通过显示映射兼容。英文分别为 Not started、In progress、Blocked、Completed、Cancelled，历史“待审核”显示 In review。保存和筛选继续使用旧值，切换语言不能改变状态、进度或预测。

未来统一为语言无关的状态 ID 时，必须另做带版本号的数据迁移、旧值读取适配和回滚验证；不能在翻译过程中批量替换原始数据。

### 演示数据与创建流程

演示文案使用独立中英文目录，以稳定任务 ID 和原始文案匹配后展示译文。232 个内置任务的标题和目标、576 条完成标准已提供英文。修改后的字段、新建用户任务与历史用户讨论保留原文；切换不修改任务 ID、状态、责任人 ID、依赖、工作量、权限或时间。英文搜索同时匹配显示名称，结果仍引用原任务。保存过的创建示例使用原始任务定义及父子关系识别，不依赖工时是否为空、估算是否确认、日期或进度快照；父任务、子任务在列表、面包屑和详情使用同一目录。空白编辑器生成的“未命名任务”按语言展示，用户自定标题保留。

高级筛选的分类、状态选项、日期预设、自定义日期及已选摘要随语言展示，查询同时支持显示名称；筛选保存值仍为原始状态和标签值。

任务创建的七组快捷示例随语言展示，首次生成的示例方案包含相应语言的任务、目标、完成标准和提示。已生成草稿与用户输入不会因为切换语言重新生成或翻译，继续可编辑。登录注册的提示、校验失败、验证码和找回密码反馈在展示层本地化。

### 活动与设置

活动类型筛选、事件动作、变更字段、状态前后值、空态及查看讨论／文件入口随语言展示；内置示例的讨论与提交说明、附件名称匹配原始任务目录后翻译。用户修改的讨论及其他自由文本保留原文。

设置的个人信息、团队信息、成员列表、我的职责及邀请弹窗接入中英文文案，包含保存、错误、权限与确认提示。内置姓名、团队名、成员责任、初始责任文档及建议证据通过身份和原始内容匹配展示英文；编辑值、角色值、权限和责任建议的应用逻辑不变。已修改的责任文档保留原文，不通过整段替换重写历史内容。

### 进度与当前情况

进度档位、来源、重新分析、燃起图图例、日期节点、时间差及节点提示随语言展示；图表先使用译文计算标签空间，日期位置与工作量保持不变。当前情况与下一步建议中的系统句式接入双语，引用内置任务、完成标准与进度记录时匹配原始目录；用户修改后的记录保留。165 组底层进度示例、周复盘示例、父任务汇总及已保存的防晒衣创建示例提供英文依据和交付节点。此能力属于本地记录展示，不代表真实 AI 服务已支持英文生成。

### AI 工具、通知与全局检查

AI 工具菜单、连接弹窗、任务上下文预览的主要字段、复制及尝试打开的结果提示随语言展示。预览使用任务 ID 匹配原始 Mock 定义，不改写导出的原始上下文；打开尝试不表述为连接成功或任务已接受。

通知的筛选与空态支持双语，三条内置通知按 ID 与原文匹配后显示译文，保留任务链接、已读状态和用户改写。文件、标签、依赖、日期和 AI 调整的静态控件补充语言目录。

主应用可达的 99 个组件纳入静态 JSX 文案检查，语言名称保留自称。该检查不覆盖所有动态变量、错误响应和文件正文，不能替代英文全流程验收。历史文件正文、选区引用与高级分析生成内容的迁移边界详见多语言检查记录。

### 日期、数字与业务时区

语言、时区和货币是独立设置。日期、数字、数量复数统一通过 Intl 格式化。英语 1 task 与 2 tasks 分开；中文使用完整数量句。人天表示工作量，不自动换算当地工资或货币。

截止日等日历日期保存为 YYYY-MM-DD，不经用户时区转换而提前或后移一天。活动等时间点保存为带时区的 ISO 时间，展示时显式使用业务确定的时区。禁止把本地化字符串作为新的存储格式。

现行“截止不得早于创建日”按 Asia/Shanghai 比较的业务基线保持有效。海外目标是由团队配置时区，旧团队默认保留 Asia/Shanghai；这属于尚未完成的业务迁移，必须同步日期校验、创建上下文、预测和历史展示，不能只改浏览器格式化器。

### AI 与接口

目标接口显式传入 `responseLocale` 与 `timeZone`，服务端独立校验；输出语言作用于新生成的说明、问题和建议，不翻译协议字段名、枚举、ID 或引用证据。用户明确要求另一种语言时按本次要求生成。语言切换不自动重跑 AI，不修改历史输出。

服务端错误逐步改为稳定错误码和结构化参数，由客户端本地化；日志保留诊断信息。现有中文错误和提示词仍是迁移项，不宣称已实现英文 AI。

### 全产品迁移顺序

先完成工作区基础层，然后依次迁移登录邀请与空团队、任务列表与筛选、创建与编辑、详情与子任务、讨论与文件、通知与账户、AI 输入输出。每条流程同时覆盖正常、空、加载、失败、无权限、数据过期、移动端与键盘状态。

英文长度增长通过弹性布局、换行和可访问全称处理，不缩小字体掩盖溢出。验收使用英文新建团队和任务，另用中文历史数据验证原文保留。新增功能必须同时补齐两种界面文案。

## 4. 验收标准

- 账户菜单中可进入语言子菜单，登录注册页面有独立入口；内置任务按目录展示英文，用户修改后保持原文。
- 首次进入默认英文，手动切换中文并刷新后保留选择；存储不可用时会话内仍可切换。
- 切换不丢失正在编辑的输入、选中任务、筛选条件或协作数据；另一浏览器标签页可同步偏好。
- 翻译目录的键与插值一致；英语零、一、多的数量显示正确；无 HTML 注入。
- 当前状态徽标翻译后写入的状态值保持兼容，中文历史任务能正常读取和筛选。
- 日历日期不因用户所在时区偏移；时间点采用显式时区；非法日期不能被静默规范化。
- 海外发布前，用户可全程用英文完成加入团队、创建任务、分配成员、讨论、文件操作和结果确认；主流程中无未迁移的系统中文文案。
- 英文 AI 链路通过请求到服务端再到结果的实际验证；未完成之前不得标记为支持。
- 移动端语言入口可触达；键盘可选择语言；英文长文本无不可访问的截断。
