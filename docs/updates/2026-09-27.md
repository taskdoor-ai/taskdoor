# TaskDoor 更新说明 · 2026-09-27

本次更新补充任务回收站、团队成员退出交接和认证页语言切换，并同步 PRD 规则、实际页面截图与测试工作台的 Jev 语义核对功能。沿用当前产品版本，不发布新版本号。

## 任务回收站

- 删除主任务时，将其全部层级子任务作为一个分支移入回收站，保留 30 天；支持恢复及彻底删除。
- 删除确认和回收站均可展开子任务名称与层级，便于核对连带操作范围。
- 左侧任务栏底部提供固定入口；支持名称搜索、分页、行内操作和本页多选。至少选择两项才显示表头批量操作。
- 拥有者可处理本团队全部回收记录；管理员和普通成员只可处理本人删除的记录。正常任务仍只有当前负责人可删除。
- 恢复会核对父任务、有效负责人、重复标识和四层限制；原父任务不存在时恢复为顶层任务。

## 团队权限与成员交接

- 引入唯一团队拥有者、所有权转让、分层成员管理及团队名称确认删除。
- 成员主动退出或被有权限的管理者移除前，须交接其负责和参与的未完成任务。
- 交接支持搜索、任务状态筛选、每页 10 项、跨页保留选择及接手人；批量设置仅影响本页已勾选任务。
- 交接保留历史贡献，写入活动和本地汇总通知；失败回滚，避免成员退出后任务责任丢失。

## 登录、注册与语言

- 登录、注册、Google 密码设置和找回密码页提供 English／简体中文切换，保留表单与邀请上下文。
- Google 新用户和未设置密码的旧用户需先设置 TaskDoor 密码，再进入工作区或继续邀请流程。
- 统一对话框、确认弹窗及部分控件样式。

## PRD 与页面截图

- 同步 PRD-0058 至 PRD-0071 的团队权限、交接、认证页和回收站规则。
- “成员退出与移除”章节专门说明退出团队和管理员移除成员；退出登录、切换团队移出本章，账号停用规则归入账号章节。
- 新增 14 张当前运行页面截图，覆盖认证页、语言菜单、交接清单、回收站空态、有数据列表、主任务及子任务删除、层级展开、多选和确认弹窗。
- 有数据回收站截图通过 localhost 独立源的示例任务实际操作生成，未改动用户原有 127.0.0.1 工作区数据；恢复和彻底删除仅采集确认弹窗，未提交。
- 更新截图清单、来源映射、实现矩阵及由 Markdown 生成的 PRD 阅读页。

## 测试工作台

- 增加 Jev 语义核对：按运行快照逐条核对预期结果及人工检查项，保留判断、概率、置信度、模型、耗时与 Token 用量。
- 通过服务端 TYPESAFE_API_KEY 配置，密钥不返回浏览器；用户点击核对才调用外部服务。
- 核对结果仅供辅助，不改写自动断言或人工验收结论；限制材料长度、核对条数与历史数量，并明确超时、限流及无有效输出反馈。
