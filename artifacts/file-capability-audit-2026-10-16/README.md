## 共同边界

- 选择与拖入使用同一白名单；同批含不支持文件时整批不添加，指出不支持项，已有文件保持；不以预置正文冒充预览。
- 仅MD、TXT／LOG、HTML源码、JSON／XML允许编辑，还须满足权限与版本规则。
- 文本下载当前查看的已保存版本；未保存草稿不替代版本下载；下载不产生新版本。
- PDF／PPT／图片下载对应版本原件，临时标注不回写原件。
- 标注是当前页面跨文件的临时修改意见，任务讨论是唯一沟通区；发送到讨论先加入草稿附件，明确发送才发布。
- 仅退役未改且无编辑记录／草稿、与原模板完全一致的内置不支持样例；用户材料、修改和历史引用保留，不物理删除blob。
- 当前上传单次最多10个文件，单个上限20MiB。PPT／PPTX依赖本地LibreOffice静态转换；文字层只影响选字，本轮区域标注目标不依赖OCR。

## 暂不支持新上传

| 格式 | 原因 |
| --- | --- |
| DOC / DOCX | 没有任意上传原件的真实文档预览；预置正文不算支持 |
| XLS / XLSX / CSV / TSV | 没有当前范围内的真实工作簿／表格上传预览 |
| ICS | 没有日历事件预览 |
| 音频 / 视频 | 没有当前播放器与时间定位标注能力 |
| ZIP / RAR / 7Z 等压缩包 | 没有只读包目录预览 |
| MDX、其他源码及专业格式 | 不在支持清单；不会因text/*或image/*泛分类而自动接收 |
