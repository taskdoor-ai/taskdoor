当前四处JSON目标示例从“交付某资料”修正为相应使用价值。父子可以复用真正适用的目的，不以目标文字不同为验收条件。人员、日期、Schema、默认主任务及用户确认边界保持。

## 定向样例

独立代理只读取当前Skill执行6个新请求，输出见[样例](examples.json)。没有读取正式任务、客户材料或日历，没有外部模型API及真实任务写入。样例是本地行为演练，不是正式模型性能基准。

| 场景 | 人工阅读观察 |
| --- | --- |
| 仓管首次扫描快速指南 | 目标是仓管能独立完成扫描，标准核对一页说明、操作与结果提示；不加安装部署 |
| 报销导出金额修复 | 目标是恢复金额一致性、支持财务对账，标准核对原始金额与导出，不改审批流 |
| 只有“整理资料” | 目的及范围待确认，补问使用对象／用途，未把归档或检索编成事实 |
| 退货说明与流程图拆解 | 父目的保留新同事理解规则与查找入口；两个子交付各有贡献与局部标准，无额外交付 |
| 两门店相同规则卡 | 保留共同目标，两张卡分别核对，不造门店差异指标，不要求目标文字不同 |
| 已有访谈归因 | 目标是减少退出原因的不确定性；标准区分证据、推断和未知，不加新访谈或开发 |
