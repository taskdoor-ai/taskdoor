# 页缩略图浮层验证（PRD-0226）

PDF 与 PPT／PPTX 统一使用默认收起的左侧短线入口；鼠标悬停打开覆盖浮层，未固定且离开／失焦后收起，点击或键盘可固定及跳页，Esc 收起并归还焦点。

## 当前实际证据

- 页面来源：主工作区当前前端构建，`http://127.0.0.1:4183/` 完整 App，1280×720。此预览仅加载文件转换服务，不能用于证明其他后端服务能力。
- PDF：真实执行手册5页；默认缩略图 canvas 为0；悬停后渲染附近页面，远处不渲染；正文 viewport 前后均696px。点击第3页后页码／当前缩略图为3，移开后关闭并释放 canvas。Tab／Enter 固定与 Esc 收起、归还焦点通过。
- PPTX：真实协同汇报8页；默认收起；悬停可见真实幻灯片缩略图，宽度保持696px；点击第2页后页码／当前缩略图均为2。
- 旧PPT与PPTX实际二进制2页夹具均转换成功，见相邻 `presentation-preview-2026-10-16` 目录；不由此推断所有Office特性均保真。
- 首次PPT转换45秒超时，最终等待限额调整为120秒；取消／超时仅终止本作业进程组并清理临时目录。
- 中文PPT首次转换存在缺字与重复首字；已确认源文件正常，原因是本机headless运行时未找到字体配置。每次作业引用现成本机字体后，真实同源请求44.47秒返回8页PDF，完整中文提取与独立渲染通过，源SHA不变。

## 最小必要检查

- 文件识别、树、标注、全屏／下载定向测试29项通过：`targeted-tests.log`。
- 转换服务8项通过，包括字体环境和取消的真实子进程回归：`service-tests.log`。
- 应用类型、服务定向类型、结构门通过。前端最终布局构建及PRD生成结果见 `validation.json`。
- 未运行全量测试或双重审查；未修改正式仓库、提交远程issue或发布版本。PPT为静态预览，不验证动画、原生编辑、生产转换部署或所有字体兼容性。真实触屏、跨端保存和外部AI交接不在本轮验收内。
