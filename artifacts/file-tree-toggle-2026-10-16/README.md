# 文件夹仅展开收起 · 2026-10-16 · PRD-0222

用户确认文件夹只用于展开／收起，不需要右侧目录列表。已删除独立目录组件及专属样式；右侧只显示当前文件预览，或无文件空态。文件夹鼠标与键盘收展不会调用文件选择，不退出编辑或标注；更多菜单保持独立。

普通桌面进入按有效树顺序选择首个未归档文件；有效明确文件目标优先，切页签保留选择。窄窗口先显示树，点击文件进入预览，返回树仍保留该文件，再点同文件也能重新进入预览。上传／新建默认在当前预览文件所在文件夹，无文件时在根目录；文件夹收展不改变落点。新建文件夹不占用文件选择；删除当前文件后回退到其他有效文件或空态。
